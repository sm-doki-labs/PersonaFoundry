# 원문 근거 표준 공장 연결 구현 계획

**Goal:** 검증한 무예시 8섹션 공정을 실제 모티브 S8 기본 경로로 연결한다.
**Architecture:** 승인 원천에서 제한된 근거 후보를 추출하고 구조 검사를 통과한 후보를 결정적으로 조립한다. 기존 G6에서 원문 해석을 검토한 뒤 확정한다.
**Tech Stack:** 기존 Python·pytest·순수 JS.
**Spec:** docs/architecture/spec.md 원문 근거 표준 절.

## 제약
개인 원문은 저장소 테스트에 넣지 않는다. 기존 수정과 revision을 보존한다. 외부 호출·배포 없이 합성 공급자로 통합 검증한다. 자동 점수로 G6를 승인하지 않는다.
