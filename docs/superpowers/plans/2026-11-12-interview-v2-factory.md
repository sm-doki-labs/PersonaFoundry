# Interview v2 Factory Implementation Plan

**Goal:** 신규 인터뷰가 기존 인터뷰 v2의 제작 절차를 밟게 한다.
**Architecture:** 승인 원문의 장면에 따라 S8 저작기를 선택한다. 질문만 분류한 결과와 검토를 통과한 관찰을 사실표와 함께 결정적으로 조립하고, 기존 G6에서 확인한다.
**Tech Stack:** Python, 기존 S8 evidence 계약과 가짜 모델 테스트.
**Spec:** PRD FR-21·23 및 D-0197.

- [x] 기본 인터뷰 라우팅과 간결한 v2 조립을 실패 검사로 고정한다. 친구는 pv6의 evidence-v4를 유지한다.
- [x] 질문만 분류, 길이 측정, 근거 카드 후보와 별도 검토를 bounded S8로 연결한다.
- [x] 새 revision 검토·승인·채팅 재현과 이전 revision 호환을 합성 자료로 확인한다.
- [x] 로컬 실행본에는 페르소나 코드만 반영하고 영상·사진·채팅 저장 데이터 및 공급자 설정을 대조한다.
