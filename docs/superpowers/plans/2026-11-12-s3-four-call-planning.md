# S3: 분석 3회와 기획 조립 1회

- 승인된 생성용 원문에서 발화자의 연속 문맥을 포함한 장면을 크기 상한 안에서 고른다. 말투, 반응·판단, 사실·한계 세 관점은 장면 ID를 붙여 각각 한 번만 분석한다.
- 기존 기획 조립기에는 세 관점에서 검증된 원문 참조와 승인 사실을 준다. 실제 원문과 화자를 대조하는 기존 검사를 유지하고 조립 호출은 한 번으로 제한한다. 자동 재시도 없이 실패 이유를 남긴다.
- 기본 경로에서는 기존 전수 태깅·빈도에 의존한 기획 검사를 사용하지 않는다. 전체 원문에서 로컬로 계산하는 말투 통계, G3 선택, 승인 산출물 읽기, S8 및 영상은 유지한다.
- 합성 원문의 적은/많은 입력에서 4회, 평가용·비공개 문장 미노출, 원문 인용 계약을 검증한다. 진행 중인 Opus 공정에 영향 없이 새 실행에서 확인한다.
