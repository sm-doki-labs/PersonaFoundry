# 프론트 생성 경로 복구 구현 계획

**Goal:** 기존 대화를 보존하면서 원문 입력부터 표준 v4 생성·검토·채팅까지 프론트에서 확인한다.
**Architecture:** 기존 UI와 native 공정을 유지하고 끊긴 설정/장면/상태 계약을 연결한다. 대화는 삭제 없이 독립 세션으로 저장한다.
**Tech Stack:** Python FastAPI, 파일 저장소, 기존 vanilla JS Foundry UI.
**Spec:** PRD v1.25 / 명세 v1.37 / LLD v1.42, D-0181.

## 제약과 검토 초점

원문·pv6·손흥민 기존 본문은 불변, 예시 대사 없음, 실제 원문을 합성 테스트에 넣지 않음, 키 값 노출 없음, 커밋/푸시 없음. 저장 실패/중복 탭 덮어쓰기/레거시 임시 기록/모델별 인증 차이/검토 대기와 실제 실패를 구분한다. 사용자 지시가 이미 범위와 실행을 승인하므로 추가 승인 대기는 하지 않는다.
