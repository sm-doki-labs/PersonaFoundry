# 말투 사용 조건 공정 구현 계획

목표: 사용자가 요청한 어휘 사용역·표현 강도·말차례 종료·표현 완화 조건을 원문에서 각각 추출하여 예시 없는 8섹션에 보존하고 익준 재생성/Gemini pv6 비교를 완료한다. 앞선 대화에서 사용자가 이 흐름의 구현과 실제 실행을 지시했다. 추가 승인·커밋·배포는 하지 않는다.

설계: 기존 전체 원문 분할·개발/확인 분리·반례 보존은 재사용한다. 새 evidence-v5는 usageAxis를 후보에 부여하고, 감사에서 조건 근거가 이전 상대 발화/턴 순서인지, 대상 답변에서 역산했는지를 별도로 기록한다. 후자는 지지에서 제외한다. 네 축의 근거 부족은 coverage에 명시하고 특징을 만들지 않는다. 최종 조립은 검증된 조건과 표현의 언어학적 기술을 그대로 넣는다. 인물별 슬랭 목록이나 예시 대사는 넣지 않는다.

대안: 일괄 슬랭 지시(개인화 부족), 모든 기능에 강도/종료를 묶은 복합 카드(부분 근거가 전체 지지로 부풀려짐), 독립적인 사용 조건 후보(채택). 의사 결정은 사용자 지정 방향을 구현하는 내부 선택이다.

- [x] 합성 회귀 테스트: 신규 기본 S8, 네 축 보존/미관찰 상태, 답변에서 역산한 조건의 지지 차단, 예시 차단, 기존 revision과 변조 검증.
- [x] v4 실행기를 전략별 호출/조립에 재사용하고 v5 추출/판독/coverage를 추가한다. 표준 신규 기본 경로를 v5로 연결하되 기존 명시 버전과 산출물을 유지한다.
- [x] 전체 생성용 원문 사본에서 새 pv7을 생성한다. 사실표·예시 없음·조건 보존·발화 ID·인용·holdout 분리를 확인한다. G6 품질 승인은 하지 않는다.
- [x] 고정 15장면×2반복×2판(96응답)을 Gemini로 새로 생성한다. 비교는 기존 pv6이며 슬랭 오버레이를 넣지 않는다. 실제 원문과 함께 이름을 가려 직접 읽는다.
- [x] 관련 및 전체 테스트, 변경 파일 정적 검사, 자료와 인계 문서를 남긴다.

검토 초점: 기존 버전 재현, 근거 없는 축의 강제 생성, 응답 유도 조건, 상태/원천 무결성, 조건 누락 또는 예시 유입. 품질 측정과 공정 구현 완료를 구분한다.

완료 기록: 11조건 pv7 생성과96응답 비교를 완료했다. 기존pv6 12·새pv7 4·불명확14로 품질 개선은 미확인이다. 테스트1,785통과. 최종 인계는 docs/status/handoffs/handoff-2026-11-11-register-conditions.md.
