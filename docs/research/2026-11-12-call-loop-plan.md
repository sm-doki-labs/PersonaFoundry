# 주제별 통화 영상 표준 구현 계획

사용자가 제공한 행동셋과 프롬프트를 실행 명세로 삼는다. 기존 대화 페르소나 pv6는 변경하지 않는다.

- 공통 보존 규칙, 장면 설정, 행동 레시피, 시간 규칙, 후처리를 분리한다. 통째 프롬프트 복제는 복장·자세 오염 위험이 있고 자유 생성만으로는 시간 조건을 놓치기 쉬워 결정론적 조립을 사용한다.
- 모티브 Lite 신규 생성은 idle + 말하기/파이팅/웃음/인사 + 유저 시그니처다. 모두 6초 생성, idle/말하기는 무편집, 일반 반응은 3초 복귀 및 2.5~3.5초 탐색, 시그니처는 4.5초 복귀 및 4~5초 탐색이다. 주어진 3.5/3.1/2.7/5초는 이전 결과값이며 고정 절단값으로 쓰지 않는다.
- contracts/video.py와 s6_actions/call_loop.py에 버전·시간·장면·선택적 중간 사진 계약과 조립기를 둔다. 기존 입력은 기존 경로로 읽는다. chapterTemplate으로 통화 목적을 정하고 나머지 외형은 기준 사진을 따른다.
- providers/base.py와 xai_video.py에 keyframes를 연결한다. 현재 공식 문서의 image/timestamp_s 형식과 1.5·720p 제약을 검증한다. 사진이 없으면 중간 사진을 전달했다고 쓰지 않는다. Lite 상품명과 1.5-lite 모델은 별개다.
- s6_actions/postprocess.py는 원본을 보존하고 무음을 강제한다. 구간 내 첫/참조 프레임 유사도와 안정 구간을 함께 보며 불확실하면 자르지 않고 검토 사유를 남긴다. 자동 점수는 인물·동작 품질 승인이 아니다.
- run.py는 생산 명세를 고정하고 비용을 6초 기준으로 계산한다. 재개/재사용은 프로필·주제·중간사진 해시까지 비교하며 후처리 실패를 재생성으로 오인하지 않는다.
- 테스트: 서로 다른 장면에 손흥민 복장/성별 누출 없음, 정확한 6개 영상과 생성 길이, 중간 프레임 요청/비용, 움직임 없는 영상·복귀 없는 영상·오디오 포함 합성 영상, 처리 재개, 기존 legacy/병렬/관문 회귀를 확인한다.
- 실제 유료 생성은 이번에 실행하지 않는다. 기존 캐릭터·채팅·승인 영상은 보존한다. 통화 재생기는 기존 승인 데이터와 호환되게 하되 음성 길이에 맞춘 새 말하기 재생 흐름은 별도 요청 범위다.
