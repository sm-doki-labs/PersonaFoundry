## 실행 목적별 모델 선택

| 목적 | 프로필 | 기준 덱에서 Argon이 맡는 단계 |
|---|---|---|
| 기본 테스트 (기본값) | `basic_test` | Gemini 3.8 Flash High로 대체한다. |
| 시연 | `demo` | Gemini 4 Argon High를 사용한다. |
| 시연 완성 전 최종 점검 | `pre_demo_completion_check` | Gemini 4 Argon High로 실행·확인한다. |

대체 대상은 성격 확정·최종 말투·대표 대사, SFT 학습 답변 생성, 오류 수정 단계다. GPT 담당 단계와 원래 Flash가 맡는 성격 초안 단계는 기존 배정을 유지한다. 기본 테스트의 Flash 사용은 의도적으로 선택하는 프로필이며, 실패 시 자동 대체와는 다르다. Flash 테스트 결과만으로 시연 완성 전 Argon 최종 점검을 완료 처리하지 않는다.

## 운영 원칙

- Gemini가 성격을 처음부터 저작한다. GPT 기본 설정 단계에서 성격 해석을 미리 완성하지 않는다.
- GPT 검토는 명시적 설정 충돌과 문맥 오류에 집중한다. 까칠함·질투·방어적 사과를 자동으로 교정하지 않는다.
- 항상/절대 행동 규칙은 관계 변화와 상황별 예외를 검토한다.
- 최종 학습 답변과 그 수정은 기준 덱에서 Argon이 맡는다. 기본 테스트에서는 Flash로 대체하고, 시연·시연 완성 전 최종 점검에서는 Argon을 사용한다. 검토 모델이 문장을 대신 작성하지 않는다.
- 기본 피드백 순환은 한 번이며, 미해결 오류에 한해 추가 수정한다.
- 형식·중복 검사는 코드로, 프롬프트 조립은 확정된 내용을 보존하는 결정적 처리로 한다.
- Terra 통과·탈락 데이터 양쪽에서 표본을 뽑아 사람이 확인하고, 이견은 Sol로 재검토한다. 표본 비율은 초기 검증 후 정한다.
- 생산마다 대화 시험을 수행하지 않지만 개발 평가 세트는 학습 데이터와 분리한다.
- 모델 실패 시 낮은 모델로 자동 대체하지 않는다. 생성 출처를 기록하고 재시도 여부를 판단한다.

## 검증 범위와 결제

현재 근거는 츤데레 단발 비교다. Flash의 초안 적합성을 확인했지만 여러 성격에 대한 일반화, Argon의 SFT 우위, Terra의 검사 정확도는 검증 전이다.

opencodex 호출이 OpenAI API 잔액 $70을 소비하는 경로인지는 확인하지 않았다. API 크레딧을 쓰려면 API 과금 경로를 별도로 확인해야 한다. Gemini 비용은 OpenAI 잔액과 별도다.
