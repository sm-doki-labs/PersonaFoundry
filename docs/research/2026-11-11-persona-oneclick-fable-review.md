# 원문 기반 페르소나 자동 생성: Fable 설계 자문

[전달한 핸드오프](../status/handoffs/handoff-2026-11-11-persona-oneclick-fable.md) · Claude CLI에 Fable 5.2, effort=high로 요청. 응답 사용량 모델: claude-fable-5-2. 아래는 자문 원문이며 수치와 효과는 실측이 아니라 제안이다.

# 설계 검토: 분석을 줄이고, 분석 생략판과 먼저 맞붙일 것

**추천은 "층화 표본 1회 직독 + 부족한 후보만 표적 검증"이고, 첫 실험에서 "분석 생략" 대조군과 비교해야 한다.** 핵심 가설(응답 전 공통 맥락 복원)은 런타임 단계로 넣지 말고 장부 필드 하나로만 반영한다. 근거는 문서의 두 관찰이다: 대조 검증의 추가 채택이 0이었고, 실제 답 대조는 세 판 모두 2/12로 같았다. 지금은 분석기를 더 정교하게 만들 근거도, 차이를 잡아낼 측정도 없다.

아래 호출 수·토큰·임계값은 모두 실측 없는 가정 또는 제안이다.

## 1. 추천 경로와 대조군

| 단계 | 입력 → 출력 | 처리 | 실행 조건 | 기존 단계 |
|---|---|---|---|---|
| S0/G0 | 원문 → 화자·관계 태그, 세션 분할, 생성/평가 분리 | 규칙 + 운영자 확인 | 대상 화자 확정 | 재사용 |
| A. 통계·층화 | 생성 원문 → 말길이·호칭·질문 비율 통계, 세션 층(전형/희귀) | 규칙 | 항상 | S3 경향 분류 대체 |
| B. 장면 직독 | 층별 표본 → 후보 성향(단서 → 관심 대상 → 첫 행동), 관계 범위, 지지·반례 장면 ID, 전제된 공통 지식, 사실·취향 | 모델 2회 병렬(전형층/희귀층) | 항상 | S3 대체 |
| C. 표적 검증 | 약한 후보 → 안 읽은 원문에서 단서 검색 후 답을 가리고 예측 | 검색은 규칙, 판정은 모델 1회(후보 일괄) | 지지 세션 3 미만이거나 반례가 있을 때만, 최대 2회 | 대조 검증을 "발견" 없이 "확인"만으로 축소 |
| S7 장부 | B·C 결과 → 등급·범위·불확실성이 붙은 장부 | 모델 1회 | 항상 | 재사용 + 필드 추가 |
| S8 | 장부 + 장면 카드 → Flash 지침 | V3 그대로 | 항상 | 고정 |

- **희귀층 분리:** 길이·어휘·응답 간격이 이상치인 세션을 따로 읽는다. 전체 일괄 읽기에서 드문 장면이 묻힌 관찰에 대한 대응이다.
- **층화 기준:** 모델 상황 분류가 아니라 규칙 특징으로 나눈다. 카톡 분류의 67%가 '기타'였기 때문이다.
- **공통 지식 필드:** 조건을 "상대가 이 대화에서 처음 꺼낸 말일 때"처럼 대화 기준으로 쓰고, "모델이 모르는 말" 기준은 금지한다. 친구판의 오발동에 대한 대응이다.

**대조군 C1(분석 생략):** A의 통계, 규칙으로 뽑은 원문 장면 K개, 같은 사실 장부를 V3 예시 칸에 그대로 넣는다. 성향 분석 호출은 0이다.

**확인 필요:** V3 예시 칸이 두 말차례 장면을 받는다고 가정했다. 못 받으면 조립기 고정 조건이 깨지므로 먼저 확인해야 한다.

**단일 인터뷰 문답:**
- 표본 없이 전량을 1회 직독하고, 떼어 둘 대화가 없으므로 C는 생략한다.
- 행동 단위는 "질문의 어느 대목을 집는가"로 한정한다.
- 행동 성향은 전부 "약한 경향"이 상한이다.
- 관계 범위는 "공적 문답"으로 잠그고, 친밀 관계 항목은 "자료 없음" 경계로 출력한다.

## 2. 예산표

토큰 가정: 인터뷰 838발화 ≈ 70k, 카톡 5,318발화(상대 발화 포함) ≈ 200k, 직독 예산 B = 60k.

| 항목 | 인터뷰 | 카톡 |
|---|---|---|
| 기본 호출 (B 2 + S7 1 + S8 1) | 4 | 4 |
| 최대 호출 (C 2회 포함) | 6 | 6 |
| 읽는 토큰, 기본 | 약 74k (B 60k + S7 8k + S8 6k) | 약 74k (원문의 약 30% 표본) |
| 읽는 토큰, 최대 | 약 104k | 약 104k |
| 최대 출력 | B 4k×2, C 1.5k, S7 3k, S8 1.5k | 동일 |
| 순차 대기 단계 | 기본 3, 최대 5 | 동일 |
| C1 호출 | 2 (사실 추출 1 + S8 1) | 2 |

- **호출 수:** 2×(관계 수) + 2 + v이고 v는 2 이하다. 발화 수와 무관하다.
- **읽는 토큰:** min(원문, B) + 14k + 15k×v 이하.
- **비용:** Σ(읽는 토큰 × 입력 단가 + 출력 토큰 × 출력 단가).
- **지연:** 순차 단계별 최장 호출의 합.
- **기존 대비:** S3는 카톡에서 133묶음이었고(관찰), 같은 40개 단위면 인터뷰는 약 21묶음이다(계산).

**캐시 키**
- S0: 원문 해시 + 화자 ID + 파서 버전
- A·B: S0 키 + 층화 규칙 버전 + 표본 시드 + 직독 프롬프트 버전 + 모델 ID
- S7: B·C 출력 해시
- S8: 장부 해시 + 조립기 버전 + 대상 관계 + 대화 모델 ID

사실 장부는 따로 캐시해 모든 비교판이 공유한다.

**추가 분석 중단 조건**
- 모든 후보에 등급이 붙었다.
- 검증 1회차에서 등급이 바뀐 후보가 2개 미만이다.
- 검증 2회에 도달했다.
- 검색으로 새 장면을 3개 이상 못 찾은 후보는 "약함"으로 확정하고 더 읽지 않는다.

**오프라인 평가(1회성, 캐릭터 생성 비용과 별도)**
- 생성: 4판 × 24장면 × 2인 × 2회 = 384 Flash 호출.
- 판정: 4개 비교 × 96쌍 × 판정자 2 = 768건이고, 8건씩 묶으면 약 96호출이다.
- 기억 문항: 12문항 × 2인 × 3판 = 72호출.

## 3. 산출물 예 (합성 인물 "도윤", 대학 동기와의 카톡)

장부 한 줄:

| 필드 | 내용 |
|---|---|
| 성향 | 모임 제안을 받으면 수락·거절 전에 누가 오는지 먼저 묻는다 |
| 관계/맥락 | 친구 카톡 한정. 직장·공적 관계는 미관찰 |
| 근거 | 독립 세션 7건 중 5건 지지. 반례 2건은 상대가 인원을 이미 말했거나 급하다고 한 경우 |
| 불확실성 | 1:1 약속에서도 그러는지는 자료 없음 |
| 등급 | 강한 경향 |

Flash 지침:

```
[항상] 반말, 한 번에 1~2줄. 장부에 없는 개인 경험은 지어내지 않고
       "기억 안 나"로 넘긴 뒤 되묻는다.
[대개] 모임 제안에는 답하기 전에 누가 오는지 한 번 묻는다.
       상대가 이미 말했거나 급하다고 하면 바로 답한다.
[가끔] 칭찬은 농담으로 받는다. 진지한 대화에서는 쓰지 않는다.
[범위] 친구 사이 기준. 다른 관계에서는 [항상]만 적용.
```

등급 구분 기준(제안):

| 등급 | 조건 | 지침 표기 |
|---|---|---|
| 무조건 | 규칙으로 셀 수 있는 형식(발화의 95% 이상)과 사실·경험 경계만 | [항상] |
| 강한 경향 | 독립 세션 3건 이상, 가린 예측 70% 이상, 반례 조건 명시 | [대개] |
| 약한 경향 | 세션 2건 또는 예측 50~70% | [가끔] + 제한, 또는 규칙 없이 장면 카드로만 |
| 미채택 | 그 이하 | 넣지 않음 |

이 기준이면 문서의 0/4는 미채택, 2/4는 약한 경향에 해당한다.

## 4. 최소 실험과 중단 기준

**누수 차단**
- 세션 단위로 평가분에서 인물당 새 24장면(가정)을 뽑는다.
- 생성 원문과 하루 이상 간격을 둔다.
- 출력을 보기 전에 규칙·시드로 장면을 고정하고 해시로 잠근다.
- 기존 진단 6장면은 제외한다.

**바꾸는 것은 V3에 넣는 행동 입력 하나뿐이다.** Flash, V3, 사실 장부, 지침 길이 상한, 장면 수는 고정한다.

| 판 | 행동 입력 |
|---|---|
| C0 | 기존 S3→S7 |
| C0′ | C0를 시드만 바꿔 재실행 |
| C1 | 분석 생략 |
| R | 추천 경로 |

**채점**
- **사람다움:** 실제 답을 보여 주고 두 판 중 관심 대상과 첫 행동이 더 가까운 쪽을 익명으로 고르게 한다. 단일 정답 일치보다 민감하다.
- **일반 자연스러움:** 실제 답 없이 1~4점으로 따로 매긴다. 자연스러움만 오르고 선호가 그대로면 인물 효과가 아니다.
- **개인 기억:** 진위는 알 수 없으므로 장부 지지 여부로만 채점한다. 문항은 장부에 있는 사실 4, 장부에 없는 경험 4, 관계 경계 4개다. 지표는 사실 회수율, 지지 없는 구체 주장(날짜·이름·장소·사건) 건수, 경계 침범 건수다.

**판정 기준**

| 결과 | 결정 |
|---|---|
| C0 대 C0′ 승률이 40~60%를 벗어나거나 판정자 방향 일치가 75% 미만 | 측정부터 고친다. 아무것도 더 만들지 않는다 |
| R이 C0 대비 동률 제외 승률 65% 이상(48장면 중 약 31승, 단측 p≈0.03 계산), 두 판정자 같은 방향, 지어냄이 C0 이하, 인터뷰 전용 판의 친밀 관계 침범 0 | R 채택 |
| C1과 R의 승률 차가 10%p 미만 | C1 채택, 분석기 개발 중단 |
| R·C1 모두 C0를 못 넘음 | 기존판 유지, 분석 추가 중단 |

마지막 경우 병목은 분석이 아니라 현장 맥락, 조립기, 측정 중 하나일 가능성이 크므로 다음 결정은 조립기 고정 해제 여부다.

손흥민은 V27과 V4-fresh의 직접 비교가 없었다. 같은 장면에 V27을 참고판으로 추가해야(+96 생성) "유지할 기존판"이 정해진다.

## 관찰과 미검증의 구분

- **관찰(문서):** 133묶음, '기타' 67%, 일괄 읽기에서 드문 장면이 묻힘, 대조 검증 추가 채택 0, 세 판 모두 2/12, 친구판 오발동.
- **미검증(제안):** 희귀층 분리의 효과, 원문 장면 직접 사용이 추상 규칙보다 낫다는 것, 공통 지식 필드의 효과, 모든 임계값과 토큰 수.
- **반증 방법:** C1이 C0를 못 넘으면 "장면 직접 사용" 주장은 기각된다. R이 C1을 못 넘으면 "분석이 값을 한다"는 주장이 기각된다.
