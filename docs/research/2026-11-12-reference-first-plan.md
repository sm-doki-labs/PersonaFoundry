# 기준 사진 확인 후 영상 생성

사용자 승인 범위: 새 모티브 Lite에서 데이터·사진·복장·배경을 입력하고, 9:16 기준 사진을 확인한 뒤 idle+행동4+시그니처의 영상6편을 만든다. 프롬프트 분기는 함께 진행한다. 기존 캐릭터·채팅·pv6를 변경하지 않는다.

- 이미지 담당: opt-in 설정, 동적 그래프, 단일 기준 이미지 생성, 합성 입력 검사.
- 화면 담당: 기존 sources/factory 입력·미리보기·확인·재생성, 화면 검사.
- 통합 담당: 서버 API, 자동 승인 차단, 확인과 실행 재개 경합 방지, 실행본 및 보존 확인.
- 공통 계약: `referenceImage:{wardrobe,background}`, 빈 문자열은 원본 유지. G4 revision과 SHA256을 확인 요청에 묶는다. 영상은 G4 승인 뒤에만 시작한다. 자동 진행/시연 설정도 이 확인을 건너뛰지 못한다.
- 검증: fake 공급자로 분기 병렬·확인 전 영상0·확인 후6·재요청 중복 방지·수정 시 새 revision을 검증한다. 실제 인물 생성 품질과 유료 공급자 결과는 별도 미검증으로 남긴다.
- 작업 경계: 기존 dirty 변경 보존. 중단했던 페르소나/품질검토 변경은 실행본에서 계속 제외. 커밋·배포·유료 호출 없음.
