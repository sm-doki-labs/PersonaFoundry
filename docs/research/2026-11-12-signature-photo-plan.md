# 시그니처 포즈 참고 사진 연결

사용자 요청: 시그니처 포즈에도 참고 사진을 넣는다. 기존 자료 접수 화면의 인물 사진과 구분해 선택 사진 한 장을 받는다. 현행 Lite의 중간 프레임 입력을 재사용하며 별도 이미지 재생성은 하지 않는다. 원본 전체가 중간 프레임이므로 기준 사진과 인물·복장·배경이 맞는 사진을 권장하고, 실제 일치 품질을 자동 보장하지 않는다.

서버: 기존 파일 업로드에 photoRole=signature를 추가한다. 검증·해시·저장소 정책을 공유하되 source-pack.photos와 인물사진 수량에는 제외한다. 실행 전에 변경/삭제 가능, 시작 후에는 읽기만 허용한다. Lite 외 등급은 무시하지 않고 제한을 안내한다. 시그니처 설명 수정이 참고 경로를 잃지 않게 한다.

화면: 전용 선택·미리보기·삭제·실패 재시도, 초안 재접속 시 미리보기 복구. 기존 스타일과 키보드 조작을 유지한다. 프론트 작업은 분리 위임하고 서버·공정·배포·문서는 주 작업자가 담당한다.

검증: 합성 사진으로 업로드/제거/다중 거절/변조 거절/재접속, 인물사진 분리, 저장소 전달, G4 확인 이후 6개 중 시그니처만 중간 프레임을 받는지 검사한다. 기존 채팅·pv6/pv2와 저장 산출물을 보존한다. 실인물 유료 호출 없이 구현과 가짜 공급자 연동까지만 확인한다.
