# 기본 성격과 추가 특질로 캐릭터 만들기

2026-10-29. [PRD §15](../product/prd.md#15-내부-제작자의-추가-특질-추천2026-10-29-d-0066), [상세 설계 §16](../architecture/lld.md#16-추가-특질-추천-구현명세-18)을 따른다.

## 제작 화면

워크숍 첫 화면의 **기본 성격 · 추가 특질** 링크를 연다. 주소는 `/trait-authoring.html`이며 `?character=<캐릭터ID>`로 바로 열 수 있다. 기존 캐릭터를 고른 뒤 “다정하지만 무뚝뚝하고, 친해지면 장난친다”처럼 성격을 입력한다. 직업·나이·성별·배경·메모는 선택 입력이다. 비운 성별은 승인 외모 명세에서 채울 수 있다.

**성격에 맞는 특질 추천받기**로 한 번에 최대5개 행동을 보거나 원하는 행동을 직접 검색한다. 추가/제거는 기본 성격을 바꾸지 않는다. 추천을 새로 받거나 다른 검색어를 입력해도 현재 선택은 유지된다. 특질을 하나도 고르지 않고 저장해도 된다. 추천 목록을 불러오지 못했을 때도 기본 성격만 저장할 수 있다. 추천은 어휘 기반 후보이므로 조합이 어울리는지 제작자가 확인한다.

저장은 새 seed revision을 만들며 기존 파일을 고치지 않는다. 다른 화면에서 먼저 저장했거나 기획이 실행/검토/승인 중이면 안내를 읽고 최신 상태를 다시 불러온다. 저장만으로 모델 호출이나 관문 승인이 시작되지는 않는다. 저장 뒤 진행 현황 화면에서 기존 기획 생성 흐름을 사용한다.

## 명령으로 사용하기

```bash
uv run cfp plan suggest --personality '다정하지만 무뚝뚝하고 자존심이 세다'
uv run cfp plan suggest --personality '다정하지만 무뚝뚝하다' --search '혼자'
uv run cfp plan seed <캐릭터ID> --personality '다정하지만 무뚝뚝하다' --trait P01-T1
```

`--trait`를 반복해 최대5개를 고를 수 있다. ID는 추천 출력에서 확인한다. 기존 씨앗을 기준으로 저장할 때 `--expected-seed-rev sd1`을 지정하면 다른 갱신을 덮어 진행하지 않는다. `plan suggest`에는 모델 호출이 없으며, 씨앗 저장과 실제 유료 생성은 별개다.

## 결과에 들어가는 내용

`selectedTraits`에는 선택한 행동 원문, 원 카탈로그와 내장 투영의 SHA256, presetId, 원 필드 경로를 보존한다. S3에서 모든 후보가 같은 제작자 선택을 유지하며 선택·말투 분리 v2에서는 각 추가 행동이 고정 요구로 의미 검토에 들어간다. S7은 상황과 일상 행동으로 확장하고 최종 disposition에는 선택한 문장이 남는다. 모델이 선택 목록을 임의로 바꾸지 못한다.

내장144개 행동은48개 허구 저작 프리셋에서 가져온 문장이다. 144개의 측정된 독립 심리 특질이나 검증된 조합을 뜻하지 않는다. SNS의4,743개 검색 장면은 이번 추천 자산에 포함하지 않았다. 실제 모델에서 자연스럽게 구현되는지와 이전보다 품질이 좋아졌는지는 별도 검증이 필요하다.
