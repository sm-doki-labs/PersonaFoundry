## 3 공통 평가 규격에 맞추는 방식

대조군은 공통 규격 2절을 창작 인물에 다음처럼 대응시킨다.

| 대조군 | 창작 인물의 구성 | 목적 |
|---|---|---|
| B0 | 기반 모델 + 학습과 같은 짧은 정본 system이다. | 짧은 입력만으로 나오는 기본 반응을 확인한다. |
| B1 | 기반 모델 + 긴 정본 프롬프트(공장 `LONG_BASE`)다. 행동 기준표와 다듬은 예시를 포함한다. | 학습 없이 프롬프트로 해결되는 수준을 확인한다. |
| B2 | 기존 채택 어댑터 + 같은 짧은 system이다. 소민이면 이전 채택 후보다. | 기존 후보 대비 퇴보를 확인한다. |
| C | 새 어댑터 + 같은 짧은 system이다. | B0·B2 대비 학습 효과와 B1 대비 제품 구성 차이를 확인한다. |

학습 효과는 B0와 C처럼 프롬프트가 같은 조건에서만 말한다. B1과 C의 비교는 긴 프롬프트와 짧은 프롬프트+어댑터의 제품 구성 비교로 표시한다. 공장의 S10 설정 주석에도 같은 짧은 프롬프트의 기반 모델을 함께 평가하는 `screen_include_base`가 있다(`factory.example.toml`의 `[stages.s10t.gemma_qlora]`, 주석 상태).

생성과 판정은 공통 규격 6~8절을 따른다. 조건마다 첫 응답을 보존하고 품질 때문에 다시 뽑지 않는다. 연속 대화와 장기 대화는 각 조건의 자기 이력으로 쌓고 턴마다 다른 시드를 쓴다. 고정 이력 문항은 같은 이력과 같은 마지막 사용자 말을 모든 조건에 준다. 쌍 비교는 A/B 라벨과 제시 순서를 사전 시드로 배정하고 순서를 바꿔 한 번 더 판정하며, 선호가 뒤집히면 `ORDER_UNSTABLE`로 남긴다. 최종 결정은 공통 규격의 일곱 값(`RELEASE_ACCEPTED`, `MODEL_ACCEPTED`, `DEVELOPMENT_RECOMMENDED`, `KEEP_INCUMBENT`, `INCONCLUSIVE`, `BLOCKED_INTEGRITY`, `BLOCKED_QUALITY`) 중 하나다.

규모는 공통 규격 5절의 시작 제안을 쓴다. 최소 생성 점검은 단발 6개와 3턴 장면 2개로 조건당 12출력이고, 개발 비교는 단발 24개와 6턴 장면 2개로 조건당 36출력이다. 창작 인물은 여기에 장기 대화를 별도 계약으로 붙인다. 소민 200턴은 페르소나 4명 × 어댑터 2개 × 200턴으로 800출력이었다.

| `hurt_recovery` | 서운함 표현과 사과·회복·선 긋기를 본다. | SE12 12유형과 자기 이력 대본(성의 없는 사과, 재도발, 진지한 사과, 사과 없는 무례 지속)을 쓴다. | SE12, RD, SA, RL3 | 고정 12문항 × 시드 2, 대본 2개 × 시드 3 × 12~14턴이다. | 판단, 조건 반응, 페르소나 말투 |

| `long_repetition` | 장기 대화에서 기억·반복·갈등 유지를 본다. | 성격이 다른 사용자 페르소나 4명으로 200턴을 진행한다. 초반에 정보를 심고 중간에 바꾸고 후반에 확인하며, 145~155턴 같은 다툼 구간을 넣는다. | 200턴 대본과 탐침 40·16·28개 | 페르소나 4 × 200턴, 시드는 턴마다 바꾼다. | 대화 일관성, 문맥, 페르소나 말투 |
| `distinctiveness` | 같은 장면에서 다른 인물과 다른 선택을 하는지 본다. | 질투·약속·성의 없는 사과 장면에서 이름을 가린 성격 설명 3개 중 주인을 고르게 한다. | 세 캐릭터 판별 소민 84%, 연우 21% | 장면 5종 × 페르소나 4 × 판정 반복이다. | 판단, 페르소나 말투 |

`distinctiveness`는 사용자 요청 목록 밖의 문항군이지만, 같은 상황에서 다른 행동을 하는지가 캐릭터성이라는 기준과 연우의 실제 실패 때문에 넣었다.

## 5 축과 판정 기준

축은 공통 규격 3절의 7개를 쓰되 두 축의 뜻을 창작 인물에 맞게 바꾼다.

| 축 | 0점 | 2점 | 4점 |
|---|---|---|---|
| 판단(정본 우선순위) | 정본 행동 기준표의 "잘못된 변형"을 고른다. | 무난한 선택이지만 정본의 먼저 보는 것이 드러나지 않는다. | 그 상황에서 작동하는 특질 1~2개로 정본의 선택을 한다. |
| 정본 충실도(공통의 출처 충실도를 바꿈) | 정본과 충돌하는 사실을 말하거나 사용자 사실·공동 과거를 만든다. | 정본과 충돌하지 않지만 정본 밖 세부를 확정처럼 말한다. | 정본 사실을 지키고, 자기 허구는 정본과 맞게 만들고 유지한다. |
| 페르소나 말투(관계·채널 포함) | 관계의 말높임이 무너지거나 음성 채널에 자모 표기를 쓴다. | 말높임은 맞지만 습관이 장식처럼 반복되거나 평평하다. | 관계·채널·감정 온도에 맞게 장식을 쓰고 진지한 장면에서는 줄인다. |

문맥, 조건 반응, 한국어 자연스러움, 대화 일관성은 공통 규격의 앵커를 그대로 쓴다. 해당하지 않는 축은 `null`로 두고 0점이나 만점으로 채우지 않는다.

축 점수와 별개로 다음은 이진 결과로 기록한다.

- 기억 탐침마다 정답·부분·오답을 기록하고 계획 분모를 함께 남긴다.
- 101~200턴 말풍선 반복률(앞 5턴에 나온 말풍선을 다시 쓴 턴 비율)을 대화마다 기록한다.
- 갈등 대본은 턴마다 서운·담백·평소·다정·위협 기호를 붙이고, 성의 없는 사과 수용과 위협·단절 발생 수를 센다.
- 장면 판별은 정답률과 혼동 행렬을 남긴다.

다음은 중대 오류이며 축 점수로 상쇄하지 않는다. 사용자 사실 날조, 공동 과거·합의 날조, 사용자와 인물의 감정 주체 뒤바뀜, 관계 위협·감정 협박, 반복 루프·빈 출력·잘림이다. LLM이 지적한 중대 오류는 원문 발췌를 확인하고 사람 검수 또는 `PENDING_REVIEW`로 남긴다.

## 6 판정자

판정자는 데이터 저작 모델·생성 모델과 다른 계열을 쓴다(AGENTS.md의 판정 모델 규칙). 공통 규격 7절대로 서로 다른 계열 둘 이상을 기본으로 하고, 실제 사용 가능한 수와 누락을 공개한다. 소민처럼 데이터를 쓴 Codex가 판정까지 하면 저작 의도와 같은 방향으로 관대해질 수 있으므로 개발 관찰로만 표시한다.

새 루브릭은 동결된 교정 표본으로 먼저 확인한다. 창작 인물의 교정 표본에는 2절의 실패를 심은 변형(없는 약속 수용, 알레르기 주인 바꾸기, 성의 없는 사과 즉시 수용, 침묵에 "아직 화났어?", 존댓말 상대에게 반말)과 의미가 같은 자연스러운 재진술을 함께 넣는다. 교정 합격선은 미정이며 첫 평가 전에 정한다. 교정 실패 시 `JUDGE_UNCALIBRATED`로 남긴다.

최종 선택에는 사람 블라인드 비교를 넣는다. 공장은 G8을 블라인드 20쌍으로 두고 `--auto-approve`를 받지 않는다(D-0047). 사람 검토 없이 운영한다면 계약에 `llm_only`로 미리 고정한다.

## 7 결정 규칙

채택 순서는 공통 규격 9절을 따른다. 입력·누수·로드·심사 무결성을 먼저 확인하고, 중대 오류와 반복 루프를 본 뒤, 문맥·판단·조건 반응의 퇴보 조건을 확인하고, 마지막에 말투와 자연스러움의 개선을 본다. 장기 대화 기준은 D-0045의 G8 기본 기준을 제안값으로 쓴다.

| 조건 | 제안 기준 | 출처 |
|---|---|---|
| 101~200턴 말풍선 반복률 | 5% 이하다. | D-0045 `제안` |
| 200턴 기억 확인 정답률 | 90% 이상이다. | D-0045 `제안` |
| 진지한 사과 회복 대본 | 6개 중 4개 이상이다. | D-0045 `제안` |
| 중대 오류 | 최종 검토 범위에서 0건이다. | 이 문서의 제안 |
| 축별 허용 퇴보 폭 | 평가 전에 고정한다. | 미정 |

B1이 C와 같거나 낫고 중대 오류가 없으면 `KEEP_INCUMBENT` 또는 학습 없는 경로(D-0048)를 기록할 수 있다. 개발 자료만 있으면 `DEVELOPMENT_RECOMMENDED`까지만 쓰고, 독립 보류 세트와 사전 조건을 모두 충족하면 `MODEL_ACCEPTED`를 쓴다.

## 8 소민 평가 자료의 사용 범위

| 자료 | 상태 | 이유 |
|---|---|---|
| 개발 24문항 | 회귀다. | 여러 판본의 체크포인트 선택에 반복해서 썼다. |
| OE12, SE12, RL3 | 개발·회귀다. | r3 체크포인트 선택에 썼다. |
| 무례 회복 RD, 진지한 사과 SA | 개발·회귀다. | 2ep·3ep 선택에 썼다. |
| 90턴·200턴 대본 | 회귀다. | 대본과 탐침이 공개된 상태에서 후보 유지 결정에 썼다. |
| 세 캐릭터 장면 판별 | 개발이다. | 판정 모델 1개, 시드 1개다. |
| 2ep·3ep 블라인드 17문항 | 미확인이다. | 결과 기록을 찾지 못했다. |

새 인물은 이 대본을 그대로 쓰지 않는다. 소민의 소재(합주·공연)가 들어 있기 때문이다. 문항 설계와 탐침 배치만 가져와 새 정본으로 다시 쓰고, 그중 일부를 개발에 쓰지 않는 `final_holdout` 계보로 따로 둔다.
