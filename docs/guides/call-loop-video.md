# 주제별 무음 통화 영상 표준

D-0191은 모티브 Lite 신규 영상의 제작 규칙이다. 기존 승인 영상과 대화 페르소나는 그대로 보존한다. Lite는 상품의 행동셋 이름이며 영상 모델 이름이 아니다. 기본 모델은 시작·끝·중간 프레임을 받는 grok-imagine-video-1.5, 해상도는 720p다.

## 구성

| 분류 | 키 | 생성 길이 | 복귀 지시 | 최종 처리 |
|---|---|---:|---|---|
| 기본 idle | idle_good | 6초 | 자세·손·입 모양 유지, 눈 깜빡임·미세 호흡만 | 6초 전체 반복 |
| 기본 말하기 | speak_good | 6초 | 보통 속도로 말하다 끝 직전 기준 표정 복귀 | 6초 전체 반복 |
| 파이팅 말하기 | cheering_good | 6초 | 오른 주먹 1~2회, 3초까지 복귀 | 2.5~3.5초 복귀 후보 탐색 |
| 웃으며 말하기 | laughing_good | 6초 | 자연스러운 웃음 1회, 3초까지 복귀 | 2.5~3.5초 복귀 후보 탐색 |
| 꾸벅 인사 | greeting_good | 6초 | 15~20도 가볍게 한 번, 3초까지 복귀 | 2.5~3.5초 복귀 후보 탐색 |
| 시그니처 | signature_good | 6초 | 지정 동작 1회, 4.5초까지 복귀 | 4~5초 복귀 후보 탐색 |

사용자가 제공한 기존 결과의 3.5·3.1·2.7·5초는 고정 절단값이 아니다. 매 생성물에서 복귀 시점을 다시 확인한다. 모든 요청은 무음 생성이며 내보낼 때 오디오 트랙도 제거한다. 생성 원본은 raw/에 보존한다.

## 프롬프트를 조립하는 규칙

1. 공통 제약은 1인 유지, 동일인·옷·배경·기존 로고 보존, 카메라 고정, 같은 첫/끝 사진, 실시간 움직임, 새 물건 금지, 무음이다.
2. 장면에는 통화 목적, 기준 자세, 복장, 배경, 언어만 넣는다. 기본 목적은 캐릭터의 FAN_CALL/FRIEND_CHAT/INTERVIEW/FAMILY_CALL 선택에서 가져온다. 구체적인 외형 설명이 없으면 기준 사진을 그대로 따르며 성별·나이·복장을 추측하지 않는다.
3. 행동은 움직이는 부위, 한 번 수행할 동작, 표정·입 움직임, 복귀 순서를 설명한다. ‘손을 뒤로 둔다’는 보편 규칙이 아니다. 기준 사진의 손 위치로 복귀한다.
4. 시간 조건은 생성 길이와 행동 종료 시점을 별도로 둔다. 반응 종료 후 새 동작을 시작하지 않는다.
5. 대화 페르소나에 예시를 넣지 않는다. 영상 프롬프트에도 경기·감사 등 특정 대사를 공통으로 박지 않고 입 움직임의 언어·속도·강도로 설명한다. 실제 음성의 정확한 립싱크를 보장하는 기능은 아니다.

‘찰칵’은 기본 행동이 아니라 시그니처 프리셋이다. `template: camera_click`은 양손 L자 프레임, 셔터 한 번, 빈손 유지, 카메라 소품 금지, 복귀를 조립한다. 다른 시그니처는 `template: custom`과 사용자가 적은 motion을 따른다.

## 장면 설정과 중간 사진

현재 화면의 기존 동작 설명 입력을 계속 사용할 수 있다. 추가 구조화 설정은 생성 초안 API의 `videoScene`, `signaturePose` 또는 설정 API `PATCH /api/sources/{cid}/settings`에서 받는다. 기존 설정을 바꿀 때 `videoTier`도 함께 전달한다.

```json
{
  "videoTier": "light",
  "videoScene": {
    "purpose": "A composed one-on-one interview.",
    "referencePose": "Standing, facing the camera, hands behind the back, slight smile.",
    "wardrobe": "Keep the exact clothing and existing insignia in the reference photograph.",
    "background": "Keep the exact sponsor wall and existing lettering in the reference photograph.",
    "language": "Korean"
  },
  "signaturePose": {
    "title": "찰칵 세리머니",
    "motion": "양손 L자 프레임을 만들고 셔터를 한 번 누른 뒤 기준 자세로 돌아온다.",
    "useWhen": "세리머니를 요청하거나 그 동작을 이야기할 때 사용한다.",
    "template": "camera_click",
    "middleFramePath": "s0-source/uploads/업로드ID/pose.png",
    "middleFrameAtS": 2.0
  }
}
```

`middleFramePath`와 `middleFrameAtS`는 선택 사항이다. 사진을 업로드한 경우에만 캐릭터 폴더 안의 실제 상대 경로를 지정한다. 다른 인물이나 다른 복장 사진을 자동으로 가져오지 않는다. 중간 사진이 없으면 두 필드를 빼며 프롬프트에도 전달했다고 쓰지 않는다. 원본 사진은 revision 안으로 복사하고 해시로 고정한다. 중간 시점은 0초 초과·4.5초 미만이다. 어댑터는 공식 API의 keyframes/image/timestamp_s 형식을 쓰고 최대4개·1/3초 격자 중복도 사전에 거절한다.

부분 `videoScene` 입력은 명시한 항목만 저장하므로 인터뷰에서 복장만 바꿔도 목적이 팬 통화로 바뀌지 않는다. API 응답·저장과 별개로 새 영상은 새 revision으로 만들어야 한다. 기존 채팅과 승인본은 덮어쓰지 않는다.

근거: [xAI 첫·끝·중간 프레임 공식 문서](https://docs.x.ai/developers/model-capabilities/video/reference-to-video#keyframes). 이 경로의 새 중간 프레임 실호출은 이번 작업에서 실행하지 않았다.

## 복귀와 무음 처리

OpenCV로 첫 프레임 및 기준 사진과 비교하되 중앙부와 작은 영역의 차이도 살핀다. 움직임이 관측된 뒤, 지정 구간에서 사진과 가깝고 연속 프레임이 안정적인 지점을 절단 후보로 고른다. 임계값 0.07·0.025와 안정 구간 0.12초는 구현 기본값이다. 얼굴·손의 정확성이나 시그니처 의미를 검증하는 모델이 아니다.

복귀 후보가 없으면 원본 길이를 유지하고 `needs_review`와 이유를 기록한다. 후보가 있어도 `qualityApproved=false`이며 G5b에서 얼굴·손·동작·이음매를 검토한다. idle/말하기는 자르지 않는다. ffmpeg로 오디오를 제거하고 ffprobe로 트랙 부재를 확인한다. 도구가 없으면 실제 유료 생성 전에 중단한다. 가짜 공급자는 `fake_unvalidated`로 구분한다.

원격 수집에 성공한 원본과 receipt를 먼저 보관한다. 후처리 실패 후 재개는 원본을 재사용하며 새 제출·비용 계획에서 제외한다. 공급자가 원격 작업 재개를 지원하지 않아도 저장한 원본을 먼저 확인한다. 원본/receipt 중 하나만 있으면 저장 중단 상태로 남기며 자동 재제출하지 않는다. 부분 재사용은 원본·receipt·중간 프레임까지 함께 옮겨 출처 경로가 끊어지지 않게 한다.

## 재생과 호환 범위

의도한 순서는 idle → 상황에 맞는 행동/시그니처 → 말하기 반복 → idle이다. 생성·승인·패키지에서 idle과 speaking을 반응과 구분하며 앱 내보내기의 speaking 슬롯으로 연결한다. 현재 로컬 채팅 화면은 기존 idle↔반응 재생을 유지한다. 음성 재생 길이에 맞춰 speaking을 반복하는 새 로컬 플레이어 흐름은 이번에 구현하지 않았다. idle이 빠진 승인본은 말하기 첫 화면 정지로 호환한다. 파이팅·큰 웃음·인사·시그니처는 임의 대체 반응으로 고르지 않는다.

이 표준의 새 프롬프트를 실제 인물 영상으로 생성해 얼굴·동작·이음매를 평가하는 작업은 아직 남아 있다. 유료 호출은 실행하지 않았다. 기존 최대6개·제출 간격1초·영상/프롬프트 분기 병렬 규칙은 유지한다.


## 기준 사진부터 만드는 프론트 흐름 (D-0192)

현재 `/studio/sources.html`에서 Lite를 고르고 원문·인물 사진 한 장·시그니처를 넣는다. 복장·배경은 선택이며 빈칸은 원본을 유지한다. `만들기 시작`은 프롬프트와 사진 준비를 병렬로 시작한다. 9:16 기준 사진이 나오면 얼굴·복장·배경·구도를 확인한다. `이 이미지로 승인 · 영상 6편 만들기`를 눌러야 영상 요청이 나간다. 프롬프트가 아직 진행 중이어도 확인할 수 있고 영상 분기는 독립적으로 시작한다.

사진이 마음에 들지 않으면 복장·배경을 고친 뒤 `기준 사진 다시 만들기`를 누른다. 이전 사진과 입력은 남고 새 revision이 생긴다. 작업 중이나 이미 확인한 사진은 수정할 수 없다. 영상이 실패하거나 서버 재시작으로 제출 전 멈추면 승인한 사진의 `이어 하기/다시 시도`를 명시적으로 누른다. 조회만으로는 재제출하지 않는다. 생성 완료는 실제 얼굴·동작·이음새 품질 검증을 뜻하지 않는다.

기존 캐릭터는 이 설정을 자동으로 추가하지 않는다. 익준 pv6·손흥민 pv2·채팅 저장소·기존 영상은 그대로 둔다. 새 흐름은 전체 자동 발행 모드와 함께 켜지 않는다.

## 시그니처 포즈 참고 사진

Lite 초안을 저장하면 인물 사진 아래의 **시그니처 포즈 참고 사진**에 선택 사진 한 장을 올릴 수 있다. 미리보기·삭제·교체가 되고 시작 뒤에는 바꾸지 않는다. 사진이 없으면 동작 설명만 쓴다.

참고 사진은 손 모양과 자세만 전달한다(D-0195). 기준 사진을 만든 직후 같은 단계에서 기준 사진과 참고 사진을 함께 넣어, 같은 인물·복장·배경에 동작만 바꾼 **시그니처 중간 프레임**을 한 장 더 만든다. 확인 화면에서 두 이미지를 함께 보고 승인하며, 승인 요청에는 두 이미지의 해시가 모두 들어간다. 승인한 중간 프레임만 시그니처 영상의 2초 지점에 들어가고, 업로드 원본은 영상 모델에 보내지 않는다. 다시 만들기는 두 이미지를 함께 새로 만든다. 이미지 생성이 한 번 늘어나며, 손 모양 정확도는 사람이 확인한다.
