# 텍스트 제작 모델 덱 연결 계획

사용자가 지정한 `persona-model-comparison-20261030/model-deck.md`와 같은 폴더의 v2 JSON을 공장 안에 snapshot으로 보존한다. 개발 호출 경로는 opencodex이며 `basic_test`가 기본이다. 별도 테스트 서버는 사용자 요청 때 주소·인증 환경변수·모델 ID 매핑을 설정한 뒤 명시적으로 선택한다. 모델 프로필과 호출 경로를 독립적으로 선택한다.

## 설계와 범위

- 기존 Python 공급자 포트를 확장한다. 단계마다 모델을 하드코딩하는 방식과 전역 text/judge만 바꾸는 방식은 역할별 배정·프로필 전환·불변 재개를 만족하지 못하므로 쓰지 않는다.
- `text_pipeline` 설정이 있는 공장만 적용한다. 기존 가짜 공급자 테스트·외부 저장소·이미지/영상·서비스 대화 모델은 보존한다.
- 역할별 task는 brief/personality/consistency/voice/scenarios/sft_answers/screening/adjudication/repair다. 기존 S3/S7/S9 역할을 연결하며 신규 호출은 기존 예산·원장을 거친다. Codex subprocess는 해당 텍스트 제작 단계에서 우회한다.
- S8은 확정 내용을 결정적으로 컴파일한다. GPT는 대사를 다시 쓰지 않고 Gemini가 초안·최종 발화·수정을 맡는다. 검토는 명시적 사실/설정/화자/문맥 오류만 대상으로 한다.
- S9에는 Terra 전수 검사와 필요 시 Sol 이견 재검토, Gemini 수정 한 번을 연결한다. 통과·탈락 표본의 사람 검토는 기존 G7a/G7에 남기고 표본 비율은 아직 정하지 않는다.
- 호출 전 task/profile/route/모델/추론 강도를 고정하고 산출물·원장에 출처를 기록한다. 경로·프로필 변경은 형성 재개 fingerprint에 반영한다. 요청 실패 시 모델/경로 자동 대체는 없다.
- CLI에서 현재 해석 결과를 보고 선택값을 `work/`에 저장한다. 테스트 경로가 미설정이면 선택 전에 거절하고 기존 선택을 보존한다. 이 명령은 모델을 호출하지 않는다.

## 검증

설정 해석, 별도 서버 URL/키 환경변수/ID 매핑, 기본 Flash 및 demo Argon, Codex 우회, HTTP 요청·원장 출처, 형성 fingerprint, S9 검수/수정 경로를 네트워크 없는 테스트로 검증하고 전체 검사도 실행한다. 이번 요청은 셋업이므로 실제 유료 호출·학습·commit/push는 하지 않는다.

## 실행 순서

1. 역할·프로필·경로 해석과 CLI 선택의 실패 테스트를 작성한다.
2. 공급자/Context/형성 fingerprint와 기존 생성 역할을 연결한다.
3. S9 검수·수정과 출처 기록을 연결하고 오프라인 회귀 검사를 돌린다.
4. 독립 코드 검토를 반영하고 PRD→명세→LLD 및 현재 상태·인계를 갱신한다.

별도 테스트 서버 주소와 인증은 사용자가 전환을 요청할 때 제공한다는 답변을 반영했다. 세부 구현 선택은 현재 구조에 맞춘 에이전트 판단이며 모델 성능·과금의 실증 근거로 쓰지 않는다.
