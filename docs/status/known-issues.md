## D-0181 검증 범위와 잔여 품질 관찰

프론트 텍스트 생성 경로는 두 합성 인물로 실제 완료했다. 영상 검토 후 재개는 합성 검사로만 검증했으며 실제 렌더링은 미실행. 합성 Gemini 표본에서 확인되지 않은 최근 행동을 부정하는 답, 언어학 용어 오차, 일반화된 답을 관찰했다. 공정 연결 성공이 모든 인물의 품질 승인은 아니다. 이전 앱이 저장하지 않았던 과거 채팅은 복구하지 못했다. 이전 실패 작업 기록은 보존된다.


### 2026-11-12 D-0192 검증 범위 (K-0123 연계)

기준 사진→명시 확인→영상6편 공정은 합성 자료와 fake 공급자로 검사했다. 복장·배경 수정의 실제 인물 동일성/구도 보존 및 실제6편 영상 품질은 아직 생성·검증하지 않았다. 승인 후 서버가 끊겨 영상 제출 전 멈추면 화면의 이어 하기 버튼으로 재개한다. 생성 실패 뒤 자동으로 유료 재시도하지 않는다. 이전에 중단한 quality-status 테스트4건은 이번 범위에서 재개하거나 수정하지 않았다.

### K-0124 — 공식 이미지 API 비용·인물 품질 검증 범위 (2026-11-12)

공식 API 연결은 합성 텍스트·사진 분석·참조 이미지 편집으로 확인했다(D-0193). 이미지의 텍스트/이미지/캐시 혼합 토큰별 비용 집계는 미연결이므로 실제 이미지 원장 금액은 null이다. 계획용 estimated_cost_usd=1.0은 추정값이며 청구 상한은 아니다. 새 이미지 모델로 손흥민 기준 사진·영상을 다시 생성하지 않았다. 이전 Grok 영상6개 검수의 인사 깊이·찰칵 손 모양·복귀 표정 문제는 별도로 남는다.

### K-0125 — 시그니처 참고 사진의 지원 범위와 품질 (2026-11-12)

D-0194 업로드·검증·전달은 합성 자료와 fake 공급자/로컬 브라우저로 확인했다. 현재 Lite에서 한 장을 시그니처 중간 프레임으로 직접 전달한다. 다른 등급으로 바꿀 때는 사진 삭제를 요구하며 업로드 중인 예약도 포함한다. 다른 복장·배경·인물의 사진을 기준 사진에 맞게 자동 재합성하지 않는다. 실제 손 모양 재현·동일성·복귀 동작 개선은 미검증이다. 기존 K-0124 영상 결함이 해결됐다고 보지 않는다.

### K-0125 갱신 (2026-11-12, D-0195)

원본 직접 전달 문제는 시드 생성으로 대체했다. 시드 생성·두 이미지 승인·S6 전달은 합성 자료와 fake 공급자로만 검증했다. 실제 이미지 모델이 손 모양을 정확히 옮기는지, 시드와 기준 사진 사이 영상 전환이 자연스러운지는 아직 실제로 생성하지 않았다. 참고 사진이 있으면 S4 이미지 호출이 2회가 된다.

### 2026-11-12 사용성 QA 후속 과제 (수정 전)

Opus 5.5 현행 화면 검토에서 같은 이름의 여러 실행 구분, 제작 상태와 대화 가능 상태의 설명, 반복되는 프롬프트 승인 본문, 승인 뒤에도 남은 사진 확인 안내, 영상6편 개별 재생 동선의 발견성, 긴 초기 폼, 단계 이름 불일치, 모바일 채팅/키보드 진입 문제가 남았다. 필수/선택 구분과 생성/품질 검증 구분은 유지하면서 화면 노출을 줄이는 제안이다. 사진 업로드2단계와 G4 승인 대기는 이번에 직접 재현하지 않았다. [근거와 우선순위](../reports/2026-11-12-usability-opus.md).
