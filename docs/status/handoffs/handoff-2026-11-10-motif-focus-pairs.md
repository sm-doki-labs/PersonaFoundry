# 두 말차례 분석: 카톡과 인터뷰

생성용 원문으로 발견·대조 각각 160쌍/인물. OpenCodex 발견 및 기존 V3 조립, Vertex Gemini 3.8 Flash 독립 대조. 카톡 후보 3개 중 1개, 인터뷰 3개 중 2개 채택. 두 인물 모두 원래 조립 입력과 대조해 분석 필드 외 차이 없음 확인. 이전 평가와 다른 장면 각 6개를 Flash(온도 0.8)로 판별 2회씩, 총 48답 생성. 익명 모델 판정: 관심/대응/엄격(각 12개) 카톡 기존 3/2/2 → 실험 4/2/2; 인터뷰 기존 0/2/0 → 실험 2/2/0. 엄격 일치는 두 번 모두 카톡 각 1/6, 인터뷰 각 0/6. 단일 모델 판정이며 사람 식별력이나 배포 효과가 아니다.

새 기능은 S8 scene_traits=true로 기존 실험 설정을 교체한다. 조립기와 기본값은 그대로다. 다음 검증은 평가 대화 추가 학습 없이 적용 조건(상대가 생소하게 제시하는 경우와 이미 서로 아는 경우, 팀과 특정 선배를 묻는 경우)을 실제 반례로 나누고, 독립 대화와 복수 판정자로 확인할 것. [검증](../verification.md) · K-0111. 배포·커밋하지 않음.
