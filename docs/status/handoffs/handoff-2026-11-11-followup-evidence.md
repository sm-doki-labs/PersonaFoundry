# 네 말차례 후속 반응 검토 · 2026-11-11

- 공장 스크립트의 선택 경로로 [연속 네 발화 추출](../../../scripts/evidence_workflow/followup.py)과 [후속 반응 검토 절차](../../../scripts/evidence_workflow/후속반응_검토.md)를 추가했다. 모델에 전달할 캐릭터 예시가 아니라 검토자가 먼저 상대 조건을 분류할 비공개 작업용 입력과 실제 네 번째 반응을 구분한다.
- 실제 원자료에서 1,946개 창을 추출해 조건 패킷은 모두 3턴, 관찰 패킷은 모두 4턴이며 ID와 앞 세 발화가 일치함을 확인했다. 합성 단위 검사 두 건으로 발화 병합, 제외 발화·대화·시간 경계, 제작·보류 메시지 중복 차단을 확인했다.
- 후속 장난을 이어가는 특정 분기는 다른 대화 3개 이상이라는 사전 반복 기준에 미달했다. 개인별 프롬프트 기본값, 서비스/n8n 설정, 모델 가중치는 변경하지 않았다. 실제 대화와 원문 ID 목록은 저장소에 추가하지 않았다.

- 후속 직접 검토에서 일곱 실제 장면의 분류를 감사했다. 두 번 일치한 경우에도 자기 설명/동조를 장난 종료/전개로 오독한 사례가 있어 과거 8건 기능 일치를 인물다움 순위로 사용하지 않는다. 두 분류기 프롬프트는 순서뿐 아니라 정의 문구도 바꿨으므로 단순 순서 효과로 단정하지 않는다. scripts/evidence_workflow/친구대화_평가기준_v2.md에 말을 받는 대상·관계 태도·표현 압축·응답 강도를 나눈 교정안을 추가했다. 인물 프롬프트는 수정하지 않았다.

- 새 평가 기준을 고정해 앞선 직접 검토 대화 묶음·기존 평가 메시지와 겹치지 않는 4개 문맥(2개 대화 묶음)을 직접 검토했다. 로컬 두 판의 후보는 버전명과 자동 판정 전에 가려 읽었다. 로컬 평가기의 실제 답 해석에서 명확한 오독 3건, 부분 해석 1건을 관찰했고, 후보 채점 JSON 8건 중 4건만 유효했다. 한 문맥 단일 추론에서도 같은 오독이 재현돼 해당 로컬 채점으로 인물다움 순위를 산출하지 않는다. 입력 조건·후보 프롬프트·평가 기준은 검증 중 변경하지 않았다. 평가모델_검증관문.md에 검사 절차를 추가했다. 서비스 생성 모델을 새로 비교하거나 배포하지 않았다.
