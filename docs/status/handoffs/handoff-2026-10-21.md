## 4. 확인한 사실과 정정

- 참조 사진과 외형 태그를 함께 주면 모델이 글을 따른다. 그래서 참조 사진이 있으면 외형 태그를 뺀다.
- 실제 흐름에서 참조 사진은 같은 외모군의 미리보기라 태그와 크게 어긋나지 않는다. 시험에서는 재생 이미지가 다른 외모군 모습이라 충돌이 크게 보였다.
- 참조 이미지를 붙인 호출은 입력 토큰이 약 5만~17만 개였다(구독 사용량).
- 보드 확장 페이지의 "G1 자동 선별"은 이제 설계와 다르다. 보드는 고치지 않았다.

## 6. 다음 할 일

1. 실제 순위 목록으로 S1(실제 Scout + 미리보기 12장) → G1(사진 선택) → S2 → G2를 한 번 돈다. 구독 사용량과 걸린 시간을 원장으로 보고한다.
2. S3 기획 초안이 `load_appearance_spec`로 외모 명세를 참조하게 연결한다(성격은 외모에서 추론하지 않는다, D-0005).
3. S4 챕터 프레임: 기준 이미지를 참조로 챕터 배경 장면 3장 → G4.
4. S5 소개 영상(Grok): 기준 이미지 → 영상. xAI 영상 API 입력·비용을 먼저 확인한다(Q-0008·Q-0009).
5. 보드의 G1 자동 선별 표시를 사람 관문으로 고친다.
