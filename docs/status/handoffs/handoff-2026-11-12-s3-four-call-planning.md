# S3 장면 분석 3회와 조립 1회 (D-0198)

- 모티브의 새 S3는 승인 원문의 생성 구간에서 장면을 고르고 말투, 반응·판단, 사실·한계를 각각 분석한다. 분석은 독립 요청 세 개로 겹쳐 실행하고, 승인 사실과 원문 인용을 쓰는 기존 기획 조립을 한 번 실행한다. 5,318개 답을 40개씩 보내던 분류 경로는 기본 제작에서 쓰지 않는다. 연구용 전수 설정은 명시할 때만 사용한다.
- 모델 분석에 빠진 영역은 빈 상태로 남긴다. 생성용 표본을 전체 빈도로 부풀리지 않는다. 로컬 말투 통계와 G3 승인, 익준 pv6의 S8 전체 반복·반례 확인, 영상 경로는 유지한다.
- 판정 모델의 공장 내부 동시 2건 상한을 기본 해제한다. 다른 공급자 제한, 공급자 자체 429 및 예산 기록은 유지한다.
- 이전 Opus 작업의 데이터와 작업 상태는 그대로 둔다. 새 실측은 별도 작업 폴더와 새 ID에서 두 인물을 원문부터 다시 만든다. 현재 브랜치의 로컬 변경이며 새 커밋·외부 발행은 하지 않는다.
- 성능 비교는 S3와 전체를 분리하며, 확인한 것은 모델을 사용하지 않은 4회 호출 계약 및 실제 기존 원문의 입력 적격성이다. 실제 새 실행 시간과 결과 품질은 새 Opus 세션에서 잰다.
- 이전 손흥민은 S8 질문 분류 응답 형식 때문에 두 차례 중단됐다. 인터뷰 분류 응답은 질문 ID로 결속하고, 불완전한 분류로 길이 규칙을 만들지 않는다. 그 경우에도 별도 저작과 근거 심사를 통과한 카드로 진행한다. 추가 모델 호출 없이 처리한다.
- 로컬 재실측은 8781의 분리된 서버와 새 결과 폴더에서 시작한다. 두 서버의 화면 응답과 새 실행본의 관련 합성 검사 138개 통과를 확인했다. 8776에 기존 진행 건이 있었으므로 이 변경을 그 실행에 적용하지 않았다.
