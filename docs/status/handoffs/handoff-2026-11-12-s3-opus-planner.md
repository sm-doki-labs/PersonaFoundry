# S3 Opus 원문 전체 분석과 S8 근거 보정 (D-0199)

- 이전 4콜 실측의 원인: 분석기가 원문의 2~3%만 봤고, 조립 재시도가 없었으며, 조립 표본이 계산 실수로 절반이 됐다. 익준 S8은 근거 5개짜리 하십시오체 카드가 들어가 말투가 흔들렸다. 손흥민 인터뷰 S8은 작성과 심사 기준이 어긋나 카드가 모두 보류됐다.
- 변경: providers/anthropic_messages.py(스트리밍, temperature 미전송, effort), Context.planner_model, S3 원문 전체 분석(analysis_input=full, 70만 자 초과 시 분할), 조립 재시도(형식 1·검사 2), 조립 표본 1,500줄·20만 자, 분석 지시의 인용부호 금지, background 근거 규칙. 친구 S8 최소 지지(대화 8개·비율 50%). 인터뷰 작성·심사 공통 범위 정의와 출처별 묶음 표본(source-cluster-v1).
- 실제 확인: Opus 분석 3회를 익준 원문 전체(호출당 입력 약 43만 토큰)에 81초, 손흥민(약 34만 토큰)에 138초에 병렬로 마쳤다. 익준은 관찰 43개가 통과했다. 손흥민은 말투 관찰 11개가 인용부호 금지에 걸려 지시를 고쳤다. 고친 지시로는 아직 다시 돌리지 않았다.
- 오프라인 전체 시험 2,312개 통과. 재실측 서버는 8782(work/s3-opus-runtime, dual-s3-opus-20261112)이며 8776·8781과 기존 실행은 건드리지 않았다.
- 미확인: 기획 조립과 인터뷰 작성 개선의 실제 결과, 전체 소요 시간, 채팅 품질.
