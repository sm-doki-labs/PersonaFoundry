## 결과

- 5개는 HTTP 200으로 접수됐으며 모두 영상 다운로드와 디코딩까지 완료했다.
- 1개(transition-6)는 최초 제출 HTTP 429로 거절됐다. 작업 ID를 받지 못했다. 재시도는 실행 스크립트의 1회 POST 보호 장치가 막았다. 로그의 Repeated paid POST blocked는 로컬 재시도 차단이고, 최초 공급자 실패는 429다.
- 성공 5편의 요청부터 다운로드까지 각각 34.34초, 38.56초, 33.52초, 34.35초, 33.50초였다. 전체 성공분 수집 완료까지 38.56초 걸렸다.

- 접수된 5편의 공개 단가 기준 추정 합계는 $1.50이다. 실제 청구 내역은 조회하지 않았다.

6개 동시 성공은 확인하지 못했다. 이번 1회 관측에서 5개 동시 접수·완료는 확인했지만, 계정의 동시 생성 상한이 5개라는 결론은 내리지 않는다. 429의 상세 응답 본문과 Retry-After는 이번 스크립트가 저장하지 않았으므로 순간 요청 빈도·활성 작업 수·계정 한도 중 무엇인지는 구분할 수 없다. 공급자 내부 GPU 실행 스케줄도 관측하지 않았다. 추가 유료 재시도는 하지 않았다.
