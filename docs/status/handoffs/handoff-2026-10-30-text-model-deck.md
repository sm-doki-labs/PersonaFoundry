# 인계: 텍스트 제작 모델 덱과 호출 경로

## 지금 상태 한눈에

개발 기본값을 opencodex/basic_test로 설정했다. 별도 test 서버는 미설정이며 사용자 전환 요청 때 주소·인증을 지정한다. 모델 프로필과 호출 경로는 독립 선택한다. 이번 세션은 셋업·오프라인 검사만 수행했으며 실제 모델 품질이나 G6/G7 승인을 올리지 않았다.

## 이번 세션에서 한 일

[모델 덱 실행 안내](../../guides/text-model-deck.md)와 [연결 계획](../../product/2026-10-30-text-model-deck-plan.md)을 작성했다. 원본 Markdown/JSON snapshot을 보존하고 역할별 공급자·추론 강도·프로필·경로 전환을 연결했다. `cfp models show/select`는 모델 호출 없이 현재 배정과 선택을 다룬다.

표준 S3는 Sol 제약 추출→Flash 성격 초안→Sol 명시적 충돌 검토→Gemini 최종 말투를 연결했다. 확인된 오류만 한 번 수정한다. S7 기존 역할도 덱을 적용하고 형성 fingerprint/recipe에 배정을 넣었다. 표준 S8은 승인 기획·특질로 현재 actor 섹션을 조립하며, 구형 short 칸은 압축하지 않은 같은 본문이다. 기존 formation 프로필은 계약을 유지한다.

S9는 Gemini 저작·Terra 전수 검사·Sol 이견 확인·Gemini 한 번 수정과 재검사를 수행한다. 원문 인용과 첫 출력·요청별 실제 모델·실패를 기록한다. 통과/탈락 표본의 사람 확인은 기존 G7a/G7에 남긴다. 모델 성능·표본 비율·청구 경로를 검증한 것은 아니다.

독립 검토의 다섯 P2를 각각 재현하고 수정했다. S8 행동 예외·시스템 규칙 보존, 미반영 G6 수정의 동일 재조립 차단, S7 실제 생성 배정과 S8 현재 선택의 구분, S3 axisNote 변경 차단을 회귀 검사로 확인한다.

최종 전체 검사825 passed/1 skipped, Ruff lint/format(352개 파일)와 diff 검사 통과다. 기존 deprecation 경고1개가 있다. 실제 외부 모델 호출은 없다.

## 결정

D-0072는 사용자 지시이며 D-0073은 기존 구조를 보존한 구현 선택이다. 자세한 내용은 [결정 기록](../decisions.md)을 따른다.

## 확인한 사실과 정정

사용자가 말한 테스트 경로는 basic_test 모델 프로필과 다른 별도 API/테스트 서버다. opencodex 선택 자체가 OpenAI API 크레딧 사용을 입증하지 않는다. 원본 모델 비교 자료는 다른 저장소에서 읽기만 했으며 원본의 standalone 표시는 snapshot의 과거 상태로 보존했다.

기존 다량의 미커밋/미추적 작업을 보존했다. 이번 요청에는 이미지·영상·서비스 추론 모델 변경이나 실제 모델 호출·학습·commit/push가 포함되지 않았다. 최신 기존 실제 실행 보고서와 생성물은 이번 셋업의 품질 근거로 재사용하지 않는다.

## 미결

K-0058에 새 덱의 실제 실행·테스트 서버·판정 정확도 미검증을 기록했다. 테스트 서버는 사용자가 전환 요청할 때 지정하므로 지금 막힌 작업은 아니다. 기존 품질 이슈와 관문 상태는 유지한다.

## 다음 할 일

사용자가 별도 테스트 서버 전환을 요청하면 `[text_pipeline.routes.test]`에 주소·인증 환경변수 이름·필요한 모델 ID 매핑을 넣고 `cfp models select --route test`로 선택한다. 같은 형성/S9 revision을 새 배정으로 재사용하지 않는다. 실제 실행 요청이 있으면 호출 계획·예산 상한을 먼저 보고하고 새 revision으로 실행한다.

시연에는 demo를, 시연 완성 전 실제 점검에는 pre_demo_completion_check를 사용한다. 프로필 선택만으로 점검 완료를 기록하지 않는다.

## 떠 있는 것

새로운 상시 서버나 외부 작업은 없다. `work/text-deck-effective-20261030.json`은 이번 유효 배정 확인 결과다. 검증의 최종 수치와 독립 검토 반영 내용은 [검증 기록](../verification.md)의 이번 날짜 항목을 따른다.
