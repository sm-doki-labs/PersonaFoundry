## 확인한 사실

- OpenAI GPT-6.1은 추론 강도가 `none`이 아니면 `temperature`를 받지 않는다. 추론 강도를 주지 않아도 기본 medium이 켜진다. 출력 상한은 `max_completion_tokens`이고 추론 토큰을 포함한다.
- OpenAI는 1,024토큰을 넘는 요청에 캐시 경계를 자동으로 만들고 캐시 쓰기를 입력 단가의 1.25배(Sol 2.50, Terra 1.25)로 청구한다.
- Gemini 호환 응답의 `completion_tokens`는 생각 토큰을 빼고 `total_tokens`는 넣는다는 보고가 있어 `총 − 입력`으로 보정한다(Q-0023, 실제 확인 전).
- demo 프로필은 2026-12-01부터 Argon 단가가 두 배(4/20)라 예산 상한도 두 배가 된다.
- 과거 중계 기록을 현재 단가로 환산하면 한지완 새 경로 약 $0.45, 선택·말투 d1 약 $0.94(둘 다 Sonnet 호출 미확인, 하한)다.
