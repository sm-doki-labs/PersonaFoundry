# 모티브 V3 원문 재생성

1. **지금 상태**: 새 모티브 기본 S8은 V3이다. 인터뷰·친구 카톡 두 인물을 별도 로컬 작업공간에서 S0부터 G6까지 만들었다. 채팅 화면이 읽는 최종 본문과 평가에 쓴 본문이 일치했다.
2. **한 일**: 공장 내장 편집 지시, S8 조립·계보·원문 키 검증, 스튜디오 대화 본문 선택, 공개 패키지 원문 제거를 연결했다. S3에서 익명 화자 표지의 이름 오탐을 고치고 필수 항목의 근거 기준을 명확히 했다. 생성과 재채점은 로컬에서 실행했으며 모델은 원격 호출했다. 푸시·배포는 하지 않았다.
3. **결정**: D-0163. 모델 덱의 유무와 관계없이 S8은 설정된 텍스트 생성 모델을 쓴다. 오리지널과 과거 모티브 revision은 유지한다.
4. **확인한 사실**: 인터뷰 모티브는 공장 41/48, 로컬 V3 38/48. 친구 카톡은 공장 34/48, 로컬 V3 두 판 각각 47/48. 카톡의 응답 길이 중앙값은 37.5자 대 16.5자·15자. 각 4상황×2회×2턴, 채점은 모델이 했다. 실험은 덱을 끈 S7 특질 시트 경로다. 전체 파이프를 반복 생성했을 때의 분산과 사람의 인물 식별률은 재지 않았다.
5. **미결**: K-0109. 카톡 원문이 짧아도 기획에서 행동 설명을 과하게 일반화하면 실제 응답은 늘어날 수 있다. 이번 비교는 원인을 분리한 실험은 아니다.
6. **다음 할 일**: 카톡에서 연속된 본인 발화와 메시지 길이 분포를 우선해 전달하는 판을 별도 실험으로 만든다. 기존 점수·질문을 고정하고 다른 채팅 화자와 새 질문에도 전이되는지 점검한다.
7. **떠 있는 것**: 새 서비스·서버 없음. 실자료·입력·채점표·생성 스크립트는 공유 작업공간의 v3-factory-qa에만 뒀으며 Git에 포함하지 않았다.
