# S8 승인 카드 컴파일러 인계 · 2026-11-11

- 요청 범위에 맞춰 기존 모티브·페르소나 조립기를 유지하고, 승인된 입력을 명시적으로 전달할 때만 실행하는 CLI를 추가했다. 배포하거나 기본 설정을 바꾸지 않았다.
- 사전 분석과 카드 검토 도구는 [scripts/evidence_workflow](../../../scripts/evidence_workflow/README.md)에 구현했다. 도구 사이의 계약은 최종 승인 JSON이다. 원문과 평가용 대화는 넘기지 않는다. 실제 친구 메신저에 적용한 검토 입력의 FACTS와 규칙 8개를 사용해 원자료부터 재조립했으며 독립 실행본과 출력이 바이트 단위로 일치했다. 비공개 자료와 인물별 카드는 저장소에 넣지 않았다.
- [실행 방법과 입력 계약](../../guides/evidence-compiler.md), [S8 구현](../../../src/character_factory_poc/stages/s8_prompts/evidence_compiler.py), [합성 입력](../../../examples/evidence/synthetic.json), [계약 테스트](../../../tests/test_evidence_compiler.py)를 확인할 수 있다.
- 합성 입력으로 모듈 CLI, 설치한 패키지 명령, 독립 실행 파일의 출력을 대조했다. 기존 페르소나 컴파일, 모티브 경로, 기본 프롬프트 바이트 회귀 검사를 함께 실행했다. 별도로 실제 친구 다음 답장 16건과 합성 3턴 대화 네 장면에서 기존판과 비교했다. 길이 개선은 관찰됐지만 대화 전반의 우세는 입증하지 못해 기본 경로는 유지한다.
