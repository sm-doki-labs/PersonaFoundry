# 실제 문답을 대화 기록으로 넣는 방식: 로컬 비교 — 2026-11-11

사용자 요청("자유롭게 진행")으로 분석기 개선을 멈추고, 기본 V3 프롬프트에서 예시를 넣는 방식만 바꿔 비교했다. 공장 코드와 파이프라인은 바꾸지 않았다. 원문 분석 호출도 추가하지 않았다. 실험 파일과 결과는 저장소 밖 로컬 작업 폴더(v3-factory-qa/scene-examples)에 있다.

## 결과

평가는 생성에 쓰지 않은 대화에서 규칙과 고정 시드로 뽑은 장면(친구 카톡 40개, 인터뷰 30개), 대화 모델은 Vertex Gemini 3.8 Flash(온도 0.8), 장면마다 1회 생성이다. 판 이름을 가리고 "실제 답에 어느 쪽이 더 가까운가"를 반응과 말투로 따로 물었고 gpt-6.1-sol과 Claude Fable 5.2가 채점했다. 아래 수치는 승-패-비김(gpt / Fable)이다. 사람 판정은 아니다.

- 같은 V3를 두 번 생성한 대조는 두 인물 모두 승패가 비슷했다(예: 카톡 반응 7-5-28 / 5-6-29). 이 채점은 무작위 차이를 승리로 읽지 않았다.
- V3에 무작위 문답 20개를 글로 더하기만 하면 카톡 답은 거의 그대로였다(답 길이 중앙값 37자 → 33자, 웃음 표기 39/40 → 37/40, 실제는 16자·10/40).
- 시스템 프롬프트를 V3의 첫 문단(AI 표시, 지어내지 않기)과 사실표로 줄이고 문답 20개를 **대화 기록(이전 턴)** 으로 넣으면 카톡 습관이 실제에 가까워졌다(14자, 웃음 16/40, 물음표 11/40. 실제 16자·10/40·8/40). 기본 V3 대비 말투 26-7-7 / 28-4-8. 반응은 9-11-20 / 8-3-29로 차이가 없었다.
- 코드로 센 습관 한 줄(길이·웃음·물음표 빈도)을 넣은 판은 지나치게 짧아지고(11자) 물음표가 1/40로 사라졌다. 지금 받은 말과 비슷한 문답을 골라 넣은 판은 무작위로 넣은 판과 반응·말투 모두 차이가 없었다.
- 인터뷰는 출처(영상·기사)마다 한 문답씩 뽑아 대화 기록으로 넣은 판이 기본 V3 대비 반응 20-3-7 / 20-2-8, 말투 20-1-9 / 23-2-5였다. 손으로 다듬은 V27과 직접 붙이면 반응 15-6-9 / 15-7-8, 말투 11-5-14 / 16-4-10으로 앞서는 쪽이지만 반응은 유의하지 않다.
- 근거 없는 구체적 주장(gpt 단독 판정): 카톡 기본 V3 3/40, 대화 기록판 1/40. 인터뷰 기본 V3 4/30, V27 11/30, 대화 기록판 8/30.

## 한계

- 인터뷰 평가 장면은 실제 답 중앙값이 234자인 기자회견 위주이고 모든 판의 답은 81~133자였다. 팬 통화 시연 장면에서는 재지 않았다.
- 카톡의 "무엇에 반응하는가"는 어느 판에서도 나아지지 않았다.
- 대화 기록에 예시를 넣는 경로는 공장의 대화 테스트 화면과 운영 서비스 어디에도 없다. 여러 턴이 이어지는 대화와 응답 지연도 재지 않았다.
- 장면마다 1회 생성, 채점자는 모델 둘이다.
