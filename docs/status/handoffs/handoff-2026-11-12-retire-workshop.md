# 옛 워크숍 진입 제거

## 지금 상태 한눈에

사용자가 생성 공정 수정을 중단시킨 뒤, 반복해서 열리는 옛 워크숍을 없애도록 요청했다. 이 작업은 그 후속 UI 진입 정리만 수행한다. 중단된 언어학 설명·제외 특징·품질 상태 변경은 작업 폴더에 미완성 상태로 보존되어 있으며 완료로 취급하지 않는다.

## 이번 세션에서 한 일

기본 주소의 워크숍 index, 구 작업실·운영 화면, studio의 갤러리·A/B/C 시안 HTML을 현재 공장으로 이동하는 최소 진입 파일로 교체했다. 실제 옛 화면 본문·스크립트 로딩은 제거했다. 주소 호환 파일은 유지하며 character/gate 문맥은 현재 공장이나 현행 검토 화면으로 전달한다. 현재 공장 설정 패널에서 사용하는 studio/d-ops 운영 기능과 공통 검토 자산은 유지한다. 검토 화면의 돌아가기 링크 및 API의 다음 화면 링크는 /studio/factory.html로 통일했다. 소스 체크아웃은 studio_dir 미지정 때도 저장소의 현재 공장 폴더를 찾는다.

## 결정

사용자 요청으로 현재 Foundry를 단일 기본 진입으로 사용한다. 옛 워크숍을 대체 화면으로 열지 않는다. 생성 공정의 중단 지시는 유지한다.

## 확인한 사실과 정정

서버 재시작 없이 실행 중인 8776 기본 주소에서 /studio/factory.html#all로 이동하고 캐릭터 6명이 표시되는 것을 브라우저로 확인했다. Python 관련 79검사와 Node 5검사가 통과했다. 전체 검사는 중단된 다른 변경이 있어 이번 범위에서 재개하지 않았다. 기존 공장 파일 2,101개 해시는 전부 동일하고, 채팅/pv6/기존 손흥민 프롬프트 관련 백업 298개도 보존됐다. 기존 서버 프로세스를 재시작하지 않아 새 Python API 링크·기본 경로 탐색 변경은 다음 시작 때 적용된다. 기존 API가 내놓는 옛 링크도 현재 정적 이동 파일에서 처리한다.

## 미결

중단된 이전 공정 수정의 통합·검증은 미완료다. 이번 수정으로 완료했다고 말하지 않는다.

## 다음 할 일

사용자 지시를 기다린다. 이전 공정 수정을 임의로 재개하지 않는다.

## 떠 있는 것

기존 로컬 서버8776 유지. 새 생성·외부 발행·커밋 없음. 보존 확인은 사용자 작업 폴더 outputs/옛_워크숍_제거_보존확인.json에 있다. 제거 전 HTML은 같은 작업 폴더 work/legacy-workshop-retirement에 보관했다.
