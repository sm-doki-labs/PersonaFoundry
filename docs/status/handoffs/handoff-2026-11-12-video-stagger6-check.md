## 실측

- HTTP 200으로 6/6 접수, 6/6 다운로드·디코딩 완료, 429 없음.
- 실제 POST 시작 간격은 1.0021 / 1.0001 / 1.0038 / 1.0025 / 1.0009초, 전체 제출 구간은 5.009초였다.
- 첫 요청부터 마지막 다운로드까지 41.61초 걸렸다. 요청 간격 대기와 5초 간격 결과 조회가 포함된다.
- 여섯 요청 모두 첫 영상 다운로드 전에 접수됐다. 서버 내부 GPU 작업의 동시 실행 여부는 관측하지 않았다.
- 전부 720×1280·24fps·49프레임이다. 공개 단가 기준 추정 합계 $1.80이며 청구 내역 조회는 하지 않았다.

직전 무간격 6건 시험은 5건 성공·1건 429였고, 이번 1초 간격 시험은 모두 성공했다. 이번 결과는 순간 요청 집중이 직전 실패 원인일 가능성을 지지하지만, 각각 1회·서로 다른 시각의 시험이므로 제한 원인을 확정하지 않는다. 6건 요청 중첩은 가능했고, 10~15초 영상이나 반복 부하에서의 안정성은 아직 측정하지 않았다.
