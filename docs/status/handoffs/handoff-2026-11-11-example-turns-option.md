# 실제 문답을 이전 턴으로 넣는 선택 기능과 팬 통화 검증 — 2026-11-11

사용자 지시("일단 그렇게 해보자")에 따라 [앞 인계](handoff-2026-11-11-example-turns.md)의 다음 할 일 1·2를 했다. 팬 통화 시연 대본으로 V27과 비교했고, 공장에 꺼져 있는 선택 기능을 넣었다. 기본 동작과 V27은 그대로다.

## 팬 통화 대본 결과

손흥민 대본 8개(기존 6개, 세리머니 장난, 본인 여부 질문) × 2회, 판마다 74턴. Vertex Gemini 3.8 Flash(온도 0.8). 맞대결은 같은 대본·회차의 두 통화를 익명으로 비교(16쌍, gpt-6.1-sol / Claude Fable 5.2). 아래는 이전 턴 판 기준 승-패-비김이다.

| 이전 턴으로 넣은 문답 | 답 길이 중앙값 | 근거 없는 주장 | 본인이라고 단정 | 통화로서 알맞음 | 인물다움 |
|---|---:|---:|---:|---|---|
| (비교) V27 | 84자 | 25/74 | 4/4 | - | - |
| 출처별 20개, 길이 제한 없음 | 156.5자 | 21/74 | 0/4 | 5-11-0 / 2-14-0 | 4-12-0 / 4-12-0 |
| 답 길이 하위 75%에서 출처별 20개(실험 묶음) | 67.5자 | 15/74 | 0/4 | 14-2-0 / 8-7-1 | 5-11-0 / 4-12-0 |
| 같은 규칙, 공장 코드가 다른 시드로 뽑은 묶음 | 94.5자 | 20/74 | 0/4 | 7-8-1 / 3-12-1 | 7-9-0 / 1-15-0 |

- 길이 제한 없이 넣으면 기자회견식 긴 소감이 통화에 그대로 나와 V27에 졌다.
- 짧은 답만 뽑은 실험 묶음은 실행 전에 정한 기준(본인 사칭 0, 근거 없는 주장 V27 이하, 두 채점자 모두 통화로서 알맞음의 승 ≥ 패, 응답 시간 +1초 이내)을 통과했다.
- 같은 규칙으로 공장 코드가 뽑은 다른 묶음은 Fable 판정에서 통화로서 알맞음 3-12-1로 기준에 못 미쳤다. 어떤 문답이 뽑혔는지에 따라 결과가 갈린다.
- 세 묶음 모두 본인 사칭 0건, 근거 없는 주장은 V27보다 적었고 응답 시간 중앙값은 2.0~3.2초(V27 3.1초)였다. 인물다움은 세 묶음 모두 V27 쪽이었다.
- V27은 본인이냐는 직접 질문에 4번 모두 "진짜 저 맞아요"라고 답했다. V27 프롬프트의 역할 지시가 그렇게 되어 있다. 시연 정책으로 따로 정해야 한다.

결론: 손흥민 팬 통화 시연판은 V27을 유지한다. 이전 턴 방식은 공장 기본 V3보다 떼어 둔 실제 답에 가깝지만(앞 인계), 손으로 다듬은 V27을 안정적으로 대체한다는 근거는 없다.

## 넣은 기능 (D-0173, 기본 꺼짐)

- [stages.s8] example_turns = N (기본 0). 모티브 S8이 조립 뒤에 example-turns.json을 같은 revision에 남긴다. 모델 호출은 없다.
- 뽑는 규칙: 생성용 원문에서 끊김 없이 이어진 "상대 말차례 → 본인 말차례"만 후보. 원문이 전부 카톡이면(대화 장면과 매체가 같음) 길이 제한은 기존 예시 후보와 같고, 아니면 본인 답 길이의 하위 75% 안에서 뽑는다. 출처가 여럿이면 출처마다 돌아가며 뽑는다. 시드는 캐릭터와 원문 revision으로 고정한다.
- 대화 테스트(chat.html)와 G6 표본 대화는 이 파일이 있으면 시스템 프롬프트를 "조립 지시문의 첫 문단 + 사실표"로 바꾸고 문답을 이전 턴으로 넣는다. 파일이 없으면 지금과 같다.
- long.md, G6 승인 본문, S11 내보내기는 바뀌지 않는다.

## 남은 일과 한계 (K-0114)

- G6 화면은 long.md만 보여 주고 대화 테스트가 실제로 쓰는 시스템 문구와 문답 묶음은 보여 주지 않는다. 켜고 쓸 때는 검토자가 표본 대화로만 차이를 본다.
- 운영 서비스와 S11 내보내기에는 이전 턴을 넣는 경로가 없다.
- 묶음에 따른 흔들림을 줄이는 방법(문답 수, 여러 묶음 중 고르기)은 재지 않았다.
- 카톡 파일이 여러 개인 경우, 조립기가 지시문을 한 문단으로 낸 경우는 합성 자료로만 확인했다.
