# 모티브 반응의 대조 검증

저장소의 기본 V3 조립기와 기존 실험 분석은 유지한다. S8에서 scene_traits=true, trait_method="contrast"를 함께 설정하면 발견 → 상대 말로만 예측 → 답의 독립 판정을 수행한다. 자료 안 양쪽에 서로 다른 반응을 고를 단서가 있고 다른 대화에서 두 갈래를 구별했을 때만 편집기에 넘긴다.

오익준 2후보, 손흥민 1후보 모두 기각. 이전 focus에서 관찰한 성향을 뒤집는 자료가 아니라 새 조건을 일반화할 근거가 불충분한 결과다. [검증](../verification.md) · K-0112. 다음 작업은 출처의 실제 맥락(이미 공유한 약속·대상 등)을 답 이전의 대화에서 복원하는 실험이다. 배포하지 않았다.
