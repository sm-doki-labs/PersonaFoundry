# 장면별 기준 페르소나 공정 적용 (D-0197)

- 새 모티브의 G0 승인 장면이 인터뷰라면 S8은 `interview-editor-v2`로 진행한다. 친구 대화 등은 기존 `evidence-v4`로 진행한다. 명시한 실험 버전이나 `interview_compiler = "inherit"` 설정이 우선한다.
- 인터뷰는 평가용·비공개 자료를 제외하고 출처별로 표본을 구성한다. 질문 분류에는 최대 180개 질문만 주고, 길이는 원문 답에서 센다. 저작·검토에는 최대 55쌍을 쓰며 길이 안내는 유형에 3개 이상 출처와 5개 이상 답이 있는 경우에만 넣는다. 모델 호출은 분류·저작·검토 각각 최대 1회(S8, 선택 응답 시험 제외)다. 실패 응답으로 호출을 소진하면 다음 명시적 재시도는 새 revision을 쓴다.
- 최종 프롬프트는 확인한 행동 조건, 승인 사실과 8섹션을 사용한다. 예시 대사를 넣지 않으며, 확인되지 않은 경험을 긍정·부정하거나 다른 이야기로 대신하지 않는다. G6 확인 이전에는 새 판을 승인하지 않는다.
- 로컬 8776 서버는 기존 영상·사진 코드와 공급자 설정을 유지한 별도 실행본으로 전환했다. 작업 폴더의 `work/persona-rollback/prepare_interview_runtime.py`로 실행본을 만들고, `apply_interview.py`로 유휴 서버만 전환한다. 이전 실행 정보는 `before-interview-server.json`에 보존했다.
- 새 판을 합성 원문으로 만들어 G6 승인 뒤 채팅에서 동일 본문이 사용되는지 검증했다. 기존 두 인물의 대화 프롬프트 SHA-256, 기존/복원된 4개 시연의 클립 응답, 설정 파일과 기존 실행 파일 3,243개가 전환 전후 동일했다. 실제 원문을 새로 생성하는 유료 실행은 하지 않았다. 인물 유사도와 실제 속도 개선 폭은 측정하지 않았다.
