## 4. 확인한 사실과 정정

- 실제 에이전트(Opus 5.5, codex_exec)는 결과 JSON을 손으로 쓰지 않고 보조 Python 스크립트로 만든다. 그 스크립트를 `/tmp`에 두면 오염 검사가 결과를 버린다.

- 오염 오류 뒤 단계 상태가 `RUNNING`으로 남는다(K-0027).
- 소요: 변형 87초, 배경 에이전트 53초 + 배경 사진 9장 302초, 장면 28초 + 자세 54초, 완성 이미지 3장 202초. 이미지 입력 토큰은 장당 약 6만~7만 개였다.
