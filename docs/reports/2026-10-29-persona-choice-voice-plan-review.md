# 특질·선택·실제 말투 개선 계획의 서브에이전트 검토

대상은 [선택·말투 개선 계획](../product/2026-10-29-persona-choice-voice-plan.md)이다. 이번 요청은 계획 수립과 검토이며 제품 구현·실제 페르소나 생성·품질 시험·학습·커밋은 실행하지 않았다.

## 1. 검토 범위와 방법

- Fermat(`01a183ad-dda5-72b2-9fa4-fd31e90fe0b1`)는 씨앗·특질·선택, S3/G3 승인·편집·정본 연결을 검토했다.
- Goodall(`01a183ad-dd8b-7fd1-96dc-dd0bee2ebcbe`)은 말투 자료의 출처, 내용 보존, S8·재개, 대조와 품질 평가를 검토했다.
- 두 검토자는 파일을 수정하지 않았고 외부 모델 실험을 하지 않았다. Goodall은 분기 반례를 메모리 내 합성 입력으로 확인했다고 보고했다. 주 에이전트는 현행 부분 문자열 분기 구현을 직접 대조했으며 별도의 실제 대화 재현은 하지 않았다.
- 주 에이전트는 지적과 현재 코드를 대조한 뒤 12건을 계획에 반영하고 수정본 재확인을 요청했다. 이는 설계 검토이며 코드 검증이나 실제 품질 합격이 아니다.
- 수정본 재검토에서 두 검토자 모두 담당한 6건이 계획에 반영됐다고 확인했고, 지정 범위에서 새로 생긴 치명적인 모순은 발견하지 못했다고 보고했다. 실제 구현·모델 품질을 확인했다는 뜻은 아니다.

## 4. 자체 점검과 잔여 조건

- 현재 S8은 기획의 말투 예시를 직접 투영한다. 새 프로필에서는 그 생성 초안이 승인 팩을 덮어쓰지 못하도록 §4.3·Task 5에 출처별 우선순위와 검사를 추가했다.
- 현재 cohort는 7장면·old/new를 강제한다. 2장면 A~D 개발 대조를 위해 별도 DevelopmentCohortV2를 제안했고 개발 결과가 QUALIFIED를 출력하지 못하게 했다.
- 기존 자료에서 실제로 재사용할 수 있는 말투 팩의 승인 증거·사용 범위는 아직 전수 감사하지 않았다. 자산이 없으면 DRAFT/VOICE_SOURCE_MISSING이며 실제 말투 경로의 완료로 표시하지 않는다.
- 새로운 의미 판정·선택기·재개·예산 경로는 모두 구현 전이다. 계획에 테스트가 있다는 사실은 테스트를 통과했다는 뜻이 아니다.
- 예시 앵커링의 인과 효과, 실제 선택 구현, 말투 전이, 누적 이력, 기본 품질선은 실제 대조와 사람/보류 평가로 확인해야 한다. K-0047의 exact tokenizer 연결 문제도 남아 있다.

이번 문서 작업의 검증은 Markdown 링크와 변경 범위 검사다. 제품 코드를 바꾸지 않아 기존 전체 테스트를 반복 실행하지 않았다. 이전 세션의 654 passed·1 skipped를 이번 변경의 새 검증 결과로 주장하지 않는다.
