원본 위치는 `/Users/johnhuh619/Documents/Codex/2026-10-14/gem/charforge/configs/characters/`의 각 `exemplars.yaml`이다. 실제 JSON 참조 경로와 바이트 해시는 [감사 원문](../../runs/experiments/20261029-choice-voice-live-r1/voice-source-audit.json)에 남겼다. 다른 저장소의 자료는 읽기만 했다.

연우 문자 10행에서 실제 문장의 연속 부분20개를 추렸다. 이는 독립적인 20대화가 아니라 **8개 원본 대화에서 나온20표현**이다. 별도 검증4행은2개 원본 대화에 속하며 주입 그룹과 겹치지 않는다. 통화·대면·영상통화와 직업/장소/날짜 정보가 직접 들어간 부분은 주입에서 제외했다. 검증 표현은 형성/렌더러에 주지 않았다.

원본 JSON 배열의 바이트는 보존했다. 필드 경로를 처리하기 위해 `records`로 감싼 무손실 사본을 만들고 원본/파생본 해시와 대응을 기록했다. JSON Pointer를 쓰는 방법도 가능하며, 원본 구조 자체에 오류가 있었던 것은 아니다. 팩의 인용은 실제 필드와 같고 styleView는 그 원문의 연속 부분이며, 원본 사건을 새 캐릭터의 정본으로 만들지 않았다.

`polished_by=user`는 기존 자료의 수정 주체 기록이다. 별도 과거 대화 검색에서 나온 자동 승인 검토 transcript는 직접적인 사람 승인 증거로 사용하지 않았다. 현재 요청에 연결한 실험 한정 재사용 권한, assistant의 감사, 새 팩의 사람 검토 미완료를 분리했다. 기록에는 `humanReviewOfNewPack=false`와 실험 한정 useScope가 있다. 처음 작성한 설명의 대화 수를 바로잡은 새 승인 기록과 팩 버전을 만들고 이전 파일도 보존했다.
