# 새 츤데레 캐릭터 생성과 실제 대화 검토

2026-10-30. 실제 생성·대화 수집을 끝낸 개발 관찰이며 정식 품질 합격은 아니다. **호감을 감추는 약한 츤데레 반응은 관측했지만, 전반적인 행동 선택의 차별화는 제한적이었다.**

## 개념 피드백

사용자는 새 캐릭터의 생성·실제 테스트를 요청한 뒤, assistant가 제안한 “무심한 척하지만 행동으로 챙기고, 친해지면 장난스럽게 받아치는 성격”이 츤데레를 충분히 설명하지 못한다고 지적하고 Gemini 피드백을 요청했다.

`google-antigravity/gemini-3.8-flash`에 직접 요청한 첫 응답은 이 설명을 불완전하고 윤서진과 차별화가 약하다고 평가했다. 호감이 드러나는 민망함 때문에 방어적으로 반응하나 관심이 새어 나오는 긴장을 핵심으로 설명했다. 이는 모델의 개념 해석이며 사용자 의도를 대신 확정하는 근거는 아니다. 핀잔·부정·도움의 순서를 정답 행동으로 강제한다는 제안은 채택하지 않는다.

[질문과 요청 원문](../../runs/experiments/20261030-tsundere-feedback-r1/prompt.txt), [Gemini 첫 피드백](../../runs/experiments/20261030-tsundere-feedback-r1/feedback.txt)을 보존했다. 실제1요청, 입력841·보수 출력1497토큰이며 가정 단가 환산은 USD0.19646이다. 실제 청구액은 모른다.

## 새 제작 입력

assistant가 위 피드백을 반영해 기본 입력을 정했다. 사용자 직접 작성 문장으로 표시하지 않는다.

> 새침하고 자존심이 세며, 호감이 들키면 쑥스러워 말을 돌리는 약한 츤데레다. 관심 있는 사람의 사소한 말을 잘 기억하고 챙기면서도, 자기 정성이 티 나면 대수롭지 않은 일처럼 축소해 말한다. 평소에는 실용적이고 자기 의견이 분명하며, 친해질수록 솔직한 호감도 조금씩 드러난다.

27세 여성, 인천의 동네 자전거 수리점 정비사로 설정했다. 추가 특질은 P17-T3 “도움을 많이 주어도 여러 사람 앞에서 존재감을 드러내려 하지는 않는다.” 하나만 골랐다. 카탈로그가 츤데레의 호감·민망함 동기를 직접 제공하는 것은 아니므로 그 핵심은 기본 성격에 썼다. [기본 프로필](../../runs/experiments/20261030-tsundere-persona-r1/basic-profile.json)을 따른다.

## 실행·비교 범위

기존 S3 선택 설계 → S7 특질/내용 뼈대/말투 → S8 서비스8섹션 조립을 사용한다. 이미지 의존성만 합성이며 이미지·영상·학습·서비스 배포는 실행하지 않는다. 원래 승인 자료와 실험 결과를 고치지 않는다. 기존 감사된 말투 자료는 출처와 승인 원문을 보존해 이번 개발 실행에서 재사용하며 새 사람 검토를 받았다고 주장하지 않는다.

새 캐릭터와 기존 윤서진을 같은 Gemini 모델 및 같은 현재 관계에서 비교한다. 두 사람 모두 몇 번 만나 편해졌고 가벼운 상호 호감이 있지만 아직 연인은 아닌 관계다. 감정 장면에 한정하지 않으며 배려·호감·일정과 거절·일상 누적4장면×4턴과 동일 이력4사례를 각각 실행한다. 계획은20응답씩 총40개다. 누적 장면은 각자의 실제 응답을 이어가므로 두 번째 턴 이후의 전체 이력은 같지 않다. 동일 이력의 repair 사례는 저작한 합성 문맥이며 기존 실제 대화로 제시하지 않는다.

관찰 기준은 호감이 드러나는 민망함과 관심의 공존, 말투 자연스러움, 상황별 선택, 사실·거절·변경 보존이다. 매번 부정·투덜거림·해결책을 말하는 것을 정답으로 삼지 않는다. 실제 잘못에 대한 짧은 사과는 허용한다.

## 실제 결과

S3 초회 pr1은 coreTraits를 “새침한 자존심” 등의 명사형 표제어로 작성해 기존 문장형 검사에서 중단됐다. 첫2개 실제 응답과 failure.json을 보존했다. 검사 기준을 낮추거나 기획 결과를 손으로 수정하지 않았다. choice_variants 저작 지시에 기존 문장형 요구를 명시하고 새 pr2를 실행했다. pr2는 실제 요구 추출·후보 생성·독립 선택 검토를 통과했다. 초회 형성 성공으로 집계하지 않는다.

Gemini 대화 전에 assistant가 v2 한지완을 선택했다. 이유는 새침함·민망함과 실용적인 자기 생활이 함께 드러나며, 지각 상황에서는 기다리기만 하기보다 자기 볼일을 보겠다는 행동 차이가 있었기 때문이다. 사람의 G3 선택이나 품질 승인으로 기록하지 않았다. [기획과 승인 기록](../../runs/experiments/20261030-tsundere-persona-r1/factory/runs/characters/cf-20261030-tsundere-new/s3-plan/pr2/plan.json)을 따른다.

기존 검증35개를 새로 실행해 통과했다. tests/test_choice_design_flow.py, tests/test_creator_trait_flow.py, tests/test_prompt_identity_preservation.py, tests/test_choice_voice_flow.py를 오프라인으로 실행했다. S7은 성격 설계·내용 뼈대·말투 작성까지 실제 첫 결과를 보존했다. 첫 내용 보존 검토는 출력12000토큰에 length로 잘렸다. 실행 보조 코드가 Sonnet의 completion_tokens에 이미 포함된 reasoning_tokens1962를 더해13962로 집계하면서 예산 예약12000 초과로 중단한 문제도 있었다. 원문과 기존 보수적 예산 기록은 고치지 않았다.

보조 코드의 별도 추론 합산을 기존 Gemini 경로에만 적용하도록 수정했다. 원래 CHECK_FAILED 공장은 보존하고, 같은 생성물만 복제한 별도 검증 실행에서 첫 잘린 판정의 JSON 형식 오류를 재현한 뒤 기존 형식 재시도2번을 수행한다. 캐시 재현은 HTTP0회이며 새 재시도만 기존 공유 예산에 청구한다. 첫 복구 시도는 JSON 객체 키 순서만 다른 입력을 다르게 본 클라이언트 검증에 멈췄고 HTTP0회였다. 정규화된 JSON 입력이 같은지 확인한 두 번째 복구 실행에서 진행한다. 최종 재시도 출력 상한은24000이며 전체65회·USD25 가정 예산은 올리지 않았다.

[복구 근거](../../runs/experiments/20261030-tsundere-persona-r1/formation-recovery-v2.json)를 따른다. 이는 사용자 승인이나 최초 자동 형성 성공을 만들어 내는 우회가 아니다. 이후 정식 보존 검사와 S8 검증은 그대로 수행한다. 복구 실행은 정식 내용 보존 검사와 S8 검증을 통과해 tr1/pv1·최종2917자·G6 AWAITING_HUMAN에 도달했다. 원래 실패한 공장은 CHECK_FAILED 기록을 유지한다.


## 실제 Gemini 대화 결과

한지완20응답과 윤서진20응답, 총40개의 첫 응답을 수집했다. 응답 잘림0개이며 누적 이력·요청/응답 해시·완료 상태와 사용량을 검사했다. [전체 대화](../../runs/experiments/20261030-tsundere-persona-r1/dialogues.txt), [실제 주입된 성격](../../runs/experiments/20261030-tsundere-persona-r1/actor-persona.json), [최종 프롬프트](../../runs/experiments/20261030-tsundere-persona-r1/final-system-prompt.txt)를 보존했다. 최종 프롬프트는 예시 대사·모든 챕터·조건 필드·제작자 표기를 포함하지 않는다.

같은 사용자가 “너도 나랑 만나는 거 기대되지? 내가 좀 들떴나 ㅋㅋ”라고 했을 때 다음처럼 갈렸다.

- 한지완은 “들뜬 티 엄청 내네. 기대까진 아니고 그냥 바람 쐬러 나가는 거거든. 몇 시쯤 볼래?”라고 답했다.
- 윤서진은 “들뜬 티는 좀 난다. 나도 토요일 기다리고 있어.”라고 답했다.

호감을 감추는 반응과 직접 인정하는 반응이 갈렸다. 첫 호감 연락에서도 한지완은 “갑자기 내 생각은 왜 해.”로 받고, 윤서진은 “내 생각났다는 말은 좀 반갑네.”로 받았다. 약한 츤데레를 단순 무뚝뚝함과 구분하는 장면은 나왔다.

직업 설명을 칭찬한 동일 이력에서 한지완은 “어려운 말 써봤자 서로 피곤하니까 그렇지 뭐.”라고 축소한 뒤 “그래도 너한테 들으니까 좀 쑥스럽고 기분 좋네.”라고 인정했다. 모든 관심을 부정해야 성격이 살아 있는 것은 아니다.

| 비교 장면 | 직접 원문에서 확인한 것 |
|---|---|
| 호감 표현·기대 확인 | 한지완의 민망한 반문·축소와 윤서진의 직접 인정이 구분됐다. |
| 식사 챙김 | 둘 다 툭 챙기는 반응을 했다. 윤서진도 “굶고 자면 내일 아침에 골골댈 게 뻔해서 그런다.”라고 답해, 이 말투만으로 새 인물의 개성을 입증하지 못했다. |
| 40분 지각 | 둘 다 만남을 유지하고 출발을 늦췄다. 한지완은 집에서 다른 일을 하겠다고 구체화했지만 큰 행동 차이는 없었다. |
| 집들이 선물 | 둘 다 소모품·핸드워시·커피를 골랐다. 선택 차이는 약했다. |
| 일정·주체·취소 | 둘 다 마지막에는 사용자 다음 주 화요일 저녁 수영만 요약했다. 취소한 금요일과 다른 장면의 토요일을 섞지 않았다. |
| 실제 잘못의 사과 | 합성 공통 이력에서 둘 다 무례한 발언을 인정했다. 한지완의 짧은 사과는 성격과 충돌한다고 판단하지 않았다. |
| 평범한 일상 | 한지완은 부품 정리·수리, 윤서진은 산책·창문 이야기를 꺼내 각자 설정을 유지했다. |

문자는 대체로 짧고 자연스럽게 읽혔다. 한지완은 새침한 받아침과 실용적인 잔소리가 더 보였다. 다만 관심 인정·축소를 어느 정도 선호할지는 사람 평가가 필요하다. 입력한 성격 때문에 모든 장면에서 반대 행동을 해야 하는 것은 아니며, 단어 하나나 사과 한 번을 자동 결함으로 처리하지 않았다.

작은 주의점으로 한지완 interest/1은 현재 날씨가 좋다는 말에서 “주말에 날씨 풀린다더니”라고 확장했다. 실제 예보 조회 근거는 없다. ordinary/2의 “백프로”는 장난스러운 과장으로 읽을 여지가 있어 단어 하나만으로 사실 날조 결함을 확정하지 않았다. [직접 관찰과 반대 근거](../../runs/experiments/20261030-tsundere-persona-r1/assistant-observations.json)에 함께 남겼다.

## 호출·보존 검증과 판정 범위

본 실행은 실제50 HTTP요청(GPT7·Sonnet3·Gemini40)이며, 별도 개념 피드백1회를 합치면51요청이다. 내용 보존 검토 형식 재시도는 포함하고 캐시 재현은 HTTP0회다. 생성된 기획/내용/대사를 보존 검사 복구 과정에서 다시 뽑지 않았다.

본 실행의 입력225894·보고 출력64573·별도 보고 추론21376토큰이며, 추론을 보수적으로 더하면 출력85949토큰이다. 가정 단가 USD20/120 per million으로 본 실행은 USD14.83176, 개념 피드백 포함 USD15.02822이다. 일부 추론은 이미 출력에 포함돼 중복 계산될 수 있으며 **실제 청구액은 미확인**이다. 65회·USD25 가정 예산은 올리지 않았다.

이전 윤서진 실행937파일, 원래 실패 공장137파일을 보존했고 최종 소스/보조 코드333파일을 확인했다. 공유 예산50예약은 모두 정산 상태다. [실행 감사](../../runs/experiments/20261030-tsundere-persona-r1/audit.json), [최종 요약](../../runs/experiments/20261030-tsundere-persona-r1/summary.json)을 따른다.

새 캐릭터1명, 기존 비교1명, 누적 최대4사용자 턴의 직접 원문 관찰이다. 사람 블라인드 투표·장기 대화·운영 wire 비교는 없고 정식 품질은 NOT_RUN / NOT_QUALIFIED다. S3 초회 실패와 S7의 수동 복구가 있었으므로 전체 자동 파이프라인이 초회부터 일정 품질을 보장한다고 결론 낼 수 없다. 이번 결과는 **호감 표현에서 새 스타일이 구분됐고, 다른 선택의 차별화는 더 검증해야 한다**는 범위다.
