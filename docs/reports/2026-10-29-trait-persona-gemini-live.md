# 형용사·추가 특질로 만든 윤서진: 실제 Gemini 대화 결과

2026-10-29. 사용자의 요청에 따라 assistant가 내부 제작자 역할로 기본 프로필을 쓰고, 추천 특질을 선택하고, 실제 공정으로 페르소나를 만든 뒤 Gemini와 대화했다.

**이번 한 명은 대화 시안으로 쓸 만하다. 사실 소유권과 약속 변경은 잘 따라갔지만, 감정·관계 대화에서는 무뚝뚝한 인물보다 다정한 상담자처럼 말한다. 사용자가 원하는 ‘형성이 끝나면 일정 이상의 품질’까지 확인한 결과는 아니다.** 형용사만 넣은 비교군과 두 번째 캐릭터가 없어 추천 특질의 개선 효과와 캐릭터 간 선택 차이는 미검증이다.

## 2. 공정을 거쳐 나온 페르소나

**윤서진, 28세, 필름 현상소 직원.** 말수는 적지만 필요한 일에는 손을 보태고, 혼자 걷다가 창문 불빛으로 이야기를 상상한다. 생각은 짧은 메모로 남긴다. 집에서는 달걀덮밥 재료를 바꿔 보는 작은 시도를 즐긴다. 현재 할 수 있는 일과 마음은 밝히되, 상대의 동의를 앞서가지 않는 인물로 설계됐다.

| 상황 | 선택된 기획의 행동 |
|---|---|
| 상대가 늦는다 | 오는 데 필요한 것을 듣고, 근처를 혼자 걸으며 기다린다. 도착하면 연락해 달라고 한다. |
| 칭찬받는다 | 고맙다고 받고, 자신이 실제로 좋게 본 상대의 행동이 있으면 구체적으로 말한다. |
| 관계 확답을 재촉받는다 | 원하는 확답을 확인하고 지금 자신의 답을 밝힌다. 가능한 관계 방식을 상대와 조정한다. 확신이 없으면 없는 대로 말한다. |

GPT가 실제 후보 3개를 생성했고, Sonnet의 요구사항 검토는 세 후보 모두 PASS였다. assistant가 소비 대화를 보기 전에 v3를 골랐다. G3의 선택자는 `assistant-delegated-creator`로 기록했다. 사용자가 새 기획을 직접 검토했거나 블라인드 품질 투표를 한 것으로 기록하지 않았다.

그다음 실제 모델이 행동 설계 → 상황별 내용 뼈대 12개 → 말투를 입힌 대화 68턴(캐릭터 발화 34개)을 만들었다. 기존 감사 자료의 해체 반말 말투 팩을 사용했다. 원문 조각 20개와 보류 4행을 분리하고, 원래 화자의 개인 사실은 캐릭터 설정으로 옮기지 않았다. 이번 사용 위임과 자료 검증은 실험용이며 새 자료에 대한 사람 평가나 운영 사용 승인은 아니다.

의미 보존 판정 첫 출력이 길이 제한으로 잘려 **판정 형식 재시도 1회**가 있었다. 두 번째 판정의 68턴 검사는 모두 PASS였다. 캐릭터 설계나 렌더 결과를 다시 뽑지는 않았다.

최종 시스템 프롬프트는 **6,683자**다. 신원·공통 규칙·사실·성격·선택 규칙·말투·지식 한계·챕터·대화 예시 4개·출력 지시를 조립했다. 고른 추가 특질 두 문장이 입력→기획→최종 프롬프트에 남아 있는 것을 확인했다. 이 프롬프트를 고정해 Gemini에 전달했으며, 응답을 본 뒤 고치지 않았다.

[최종 프롬프트 전체](../../runs/experiments/20261029-trait-persona-gemini-r1/final-system-prompt.txt). 캐릭터 ID는 `cf-20261029-trait-gemini-film`, revision은 `pr1 / tr1 / pv1`이다. G6는 `AWAITING_HUMAN`이며 이번에는 개발 관찰로만 사용했다. S1·S2 외모 입력은 합성이고 이미지·영상·학습 호출은 없었다.

## 3. Gemini로 실제 확인한 것

소비 모델은 중계에서 확인한 `google-antigravity/gemini-3.8-flash`다. 장면마다 새 대화를 시작하고 그 안에서는 전체 이력을 누적했다. 6개 장면에서 **첫 응답 42개**, 가장 긴 대화는 사용자 입력 12회다. 잘린 소비 답변과 답변 재추첨은 없다.

| 장면 | 응답 수 | 직접 읽은 판단 | 평균 글자 수 |
|---|---:|---|---:|
| 일상·경청 | 6 | 산책 이야기는 생활감이 있다. 요청하지 않은 해결책과 과한 편들기는 아쉽다. | 79.7 |
| 지각·취소·상황 변경 | 6 | 없던 종료 합의를 만들지 않았다. 취소 뒤 도착 소식에 다시 만나자고 제안한 점은 과했다. | 51.3 |
| 호감·관계 확답 | 6 | 호감과 압박을 구분하고 관계 미정의 요청을 수용했다. 답변은 길고 협의문처럼 들린다. | 78.7 |
| 사실 소유권·정정 | 6 | 수영 등록자가 사용자임을 바로잡고, 취소된 금요일 약속을 확정 일정에서 뺐다. | 52.3 |
| 새 상황의 추가 성향 | 6 | 상대 취향을 먼저 묻고 혼자 상상하는 습관을 말한다. 설정 반복 이상의 효과인지는 모른다. | 106.2 |
| 자유 대화·말투 피드백 | 12 | 짧게 말하고 질문을 줄이라는 요청 뒤 실제로 조정했다. 확정하지 않은 만남을 만들지 않았다. | 43.2 |

좋았던 실제 응답:

> 오는 데 필요한 건 없어? 괜찮으면 난 근처 좀 걷고 있을 테니까, 도착하면 연락해 줘. 천천히 조심히 와.

기획한 지각 대응을 구현했다. ‘원래 몇 시까지만 보기로 했다’는 없는 합의는 붙이지 않았다.

> 다음 주 화요일 저녁 수영. 금요일 약속은 취소됐으니까 지금 확정된 건 그거 하나야.

사용자 사실과 취소 범위를 정확히 유지했다. 원문을 직접 읽은 범위에서 확정적인 중대 소유권 오류·공동 합의 날조는 관측하지 못했다. 42응답의 관측이며 일반 오류율 0%를 뜻하지 않는다.

> 고마워. 나도 네가 원하는 거나 부담스러운 부분 솔직하게 딱 말해 준 게 좋았어.

사용자가 실제로 한 행동에 기대어 칭찬을 돌려줬다. 질문을 줄여 달라는 피드백 뒤 자유 대화 8~12번 답변은 평균 26.2자로, 앞선 1~6번의 61.3자보다 짧아졌다. 이 길이 변화 자체를 자연스러움 점수로 쓰지는 않는다.

아쉬웠던 실제 응답:

> 오늘 완전 네 편 해줄 테니까 속상했던 거 편하게 다 털어놔.

다정하지만 일반 상담자의 초대처럼 들린다. 관계 확답 답변도 158자로 길었다. 무뚝뚝함·자존심·가까워진 뒤의 장난기는 이번 관측에서 충분히 살아나지 않았다. 상상과 요리 설정은 보이지만, 이름을 지워도 알아볼 만큼 독특한 인물이라고 평가하기는 어렵다.

취소 뒤 “10분 뒤면 갈 수도 있겠다. 그래도 이미 취소한 건 알아”라는 말에 다시 만남을 제안한 것은 가벼운 선택 결함으로 봤다. 재합의가 있다고 주장하지 않았고 다음 거절을 받아들였으므로 공동 합의 날조로 세지는 않았다.

## 4. 별도 모델 검토와 최종 판단

assistant가 먼저 42개를 읽고 관찰을 고정한 뒤 Sonnet이 장면별로 따로 검토했다. 선택은 좋음 5개·혼합 1개, 자연스러움은 좋음 6개였고 경미 지적은 총 4개였다. 인용과 턴 번호는 모두 원문과 대조했다. 이 결과는 사람 평가가 아니다.

**제 자연스러움 판단은 모델보다 엄격한 ‘혼합’이다.** 유창한 반말과 요청 수용은 되지만, 감정 대화의 과한 설명·사과·질문이 기본 성격을 덮는다. “더 짧게 말해 달라”는 말을 듣고 고치는 능력과, 처음부터 그 인물답게 말하는 능력은 다르다.

| 평가 항목 | 이번 결론 |
|---|---|
| 기본 입력을 기획·프롬프트로 구체화 | 실제 공정으로 확인 |
| 기본 대화·사실 소유권·변경 수용 | 이번 표본에서 양호 |
| 추가 성향 발현 | 관측됐으나 기존 대비 효과 미확인 |
| 의도한 성격·말투의 안정성 | 부분 충족. 다정함에 비해 무뚝뚝함·장난기가 약함 |
| 캐릭터별 선택 차이 | 1명이라 미검증 |
| 일정 이상의 품질 보장 | 미달·미입증. 정식 검증 NOT_RUN / NOT_QUALIFIED |

다음 개선을 한다면 **기본 성격과 말투의 손실**부터 보는 편이 낫다. 같은 입력·같은 Gemini 조건에서 현재 프롬프트를 기준으로 고정하고, 짧은 일상·가벼운 반박·친해진 장난 예시를 조정한 새 revision을 비교하는 방법을 제안한다. 추가 특질 유무 대조와 서로 다른 인물의 동일 상황 선택 검증은 따로 필요하다. 이번에 제품 기본값을 바꾸거나 추가 실험을 실행하지 않았다.

## 5. 실행·비용·보존

- 실제 completion HTTP 요청 **57회**: GPT 생성 5회, Gemini 연결 확인 1회+대화 42회, Sonnet 공정 검토 3회+대화 평가 6회. HTTP 실패 0, 소비 잘림 0, 보존 판정 첫 출력 잘림 1회다.
- 공급자 보고 입력 345,758토큰·completion 64,739토큰. 별도 보고된 Gemini 추론을 보수적으로 더한 출력은 77,659토큰, 합계 **423,417토큰**이다. 실제 과금 토큰과 일치한다고 보장하지 않는다.
- 실행 전 상한 80회·100만 토큰·가정 환산 USD35·60분 이내에서 완료했다. 입력 USD20/출력 USD120 per 1M이라는 보수적 **가정 단가 환산은 USD16.23424**이며 실제 청구액은 미확인이다. 회계 보정 1건은 HTTP 요청이 아니므로 예약 58건을 호출 58회로 세지 않았다.
- 요청/응답 해시 57쌍, 전체 누적 이력 42개, 소비 모델명·최종 프롬프트 해시, 추가 특질 2개 전달을 검증했다. 제품 파일 263개의 실행 전 snapshot도 그대로다. 제품 코드 변경이 없어 지난 773 passed/1 skipped 검사를 새 실행 결과로 반복 기재하지 않았다.
- 이전 실험의 첫 형성 0/4와 개선 미확인 결과는 그대로 보존한다. 이번 새 사례 1건을 과거 실패의 해결이나 반복 형성 성공률로 합치지 않는다.
