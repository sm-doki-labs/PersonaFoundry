# 평가 모델을 자동 순위 산출에 쓰기 전 확인

친구대화_평가기준_v2.md의 네 축을 쓴다. 원답을 직접 읽은 교정 담당자가 먼저 현재 주제, 반응 대상, 실제 발화 기능, 허용할 대안, 제공되지 않은 정보를 기록한다. 후보 이름과 모델 판정은 그 뒤 확인한다.

모델에는 다음 작업을 분리한다.
1. 후보가 없는 상태에서 실제 마지막 발화가 누구의 어느 말에 반응하고 무엇을 하는지 근거와 함께 설명한다.
2. 정의 문구는 고정하고 후보 위치만 바꿔 네 축을 개별 채점한다. 사실 경계 및 정상 답장 형식 오류를 별도로 확인한다.
3. 형식 유효성, 자료에 없는 근거, 이유와 점수의 모순, 화자·대상·시제 오독을 점수 집계 전에 확인한다. 출력 끝에 토큰/다른 화자 발화를 붙인 후보는 정상 답장처럼 채점하지 않는다.
4. 같은 입력의 단일 실행과 배치 실행에서 문제가 재현되는지 필요에 따라 한 번 확인한다. 화자 표기를 바꾸는 진단은 기준 검증의 반복 표본으로 세지 않는다.

근거를 읽지 못하거나 이유에 실패라고 쓰면서 점수는 만점을 주면 해당 결과를 자동 순위에 사용하지 않는다. JSON 파싱을 수리했다고 문맥 해석이 맞아지는 것은 아니다. 작은 교정 집합에서 고친 프롬프트는 그 집합에서 성능이 검증됐다고 하지 않고 새 자료로 다시 확인한다. 서비스 모델과 다른 모델의 생성 결과를 서비스의 품질로 직접 일반화하지 않는다.
