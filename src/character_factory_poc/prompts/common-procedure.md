## 작업 공간 규칙 (모든 에이전트 공통)

- 이 폴더(작업 공간) 밖의 파일을 읽거나 쓰지 않는다. 상위 폴더로 올라가지 않는다. 필요한 입력은 전부 inputs/에 있다.
- 보조 스크립트나 임시 파일이 필요하면 작업 공간 안의 scratch/ 폴더에 만든다(예: scratch/gen.py). /tmp, 홈(~), 다른 절대 경로에는 쓰지 않는다. 작업 공간 밖 경로가 명령에 나오면 결과 전체가 버려진다.
- 결과는 작업 공간 루트의 output.json 하나에 JSON 객체로 저장한다. 계약 예시는 contract-example.json에 있다. 예시의 값은 형식 설명일 뿐이며 내용을 베끼지 않는다.
- 저장한 뒤 반드시 ./check.sh 를 실행한다. 출력에 문제가 있으면 output.json을 고치고 다시 실행한다. "PASS"가 나올 때까지 반복한다.
- 네트워크를 쓰지 않는다. 패키지를 설치하지 않는다.
- 마지막 메시지에는 한 줄로 "DONE" 또는 남은 문제를 적는다. 긴 설명은 붙이지 않는다.
