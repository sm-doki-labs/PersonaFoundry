# character-factory-poc

기획 브리프와 화제성 순위 목록에서 캐릭터 한 명을 만든다. 레퍼런스 선별과 얼굴 고르기, 기준 사진, 캐릭터 기획, 챕터 배경·자세·완성 이미지, 소개·동작 영상, 상세 특질, 긴·짧은 프롬프트, SFT 데이터와 학습, ID를 맞춘 릴리즈까지를 단계별 에이전트가 제안하고 수행한다. 사람은 정해진 관문에서 고르고, 직접 정의하고, 승인한다.

## 지금 상태

- 구현돼 있고 오프라인 테스트를 통과하는 단계: S1 레퍼런스 → G1 → S2 대표 이미지 → G2 → S3 씨앗·변형 → G3 → S3r 참고 자료(골격) → S4a 배경 → G4a → S4b 장면 사실·자세 → G4b → S4 완성 이미지 → G4 → S6 동작 영상(골격, 가짜 영상만) → G5b, S5 소개 영상 9:16 → G5, S7 특질 → S8 프롬프트 → G6. 배경 사진과 완성 이미지에는 비전 자동 검사·수정 루프가 붙어 있다. 설계는 2026-10-27부터 G2를 없애고 S2를 자동 기준 사진·동일인 검사로 바꿨지만 코드에는 아직 반영하지 않았다(D-0042, K-0034).
- 실제 모델로 한 번 돌려 다음 관문까지 간 것(L2): S2 대표 이미지, S3 씨앗·변형, S4a 배경, S4b 장면·자세, S4 완성 이미지(데모 캐릭터, G4 대기), 페르소나 축 S7·S8(P29 2명, G6 대기). S1과 S5는 일부만 실제로 확인했고, 비전 자동 검사는 아직 실제로 돌리지 않았다.
- 설계만 있는 단계: S9 데이터, S10 학습·평가, S11 릴리즈, 앱 형식 내보내기.

단계별 현황과 다음 할 일은 [현재 상태](docs/status/current-state.md), 지금 안 되는 것은 [알려진 문제](docs/status/known-issues.md)에 있다. 개발 검증은 `scripts/check.sh`, 페르소나 축 실행은 [페르소나 축 실행 안내](docs/guides/persona-runbook.md)를 따른다.
