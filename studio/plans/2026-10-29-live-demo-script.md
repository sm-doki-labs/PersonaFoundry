공장 현장 크게 보기 기준. 화면의 시간·비용·문구는 시안 각본 값이다.

## 리허설 측정 (2026-10-29, 1512×982, 2×)

대본 문장을 초당 4음절로 읽는다고 보고, 문장마다 0.5초씩 쉬며 실제 화면을 조작해 처음부터 끝까지 녹화했다(recordings/rehearsal-live-1512.mp4, 4분 43초). 측정에는 즉흥 설명, 질문, 작업실에서 후보를 오래 보여 주는 시간이 들어가 있지 않다. 그래서 아래 **권장 시간**은 측정값에 그 여유를 더한 값이다.

리허설에서 알게 된 점:

- 작업실 왕복(클릭 → 고르기 → 확정 → 공장 복귀)은 실제로 8~9초다. 그중 확정 뒤 돌아오는 데 1.3초가 걸린다.
- 장면 5에서 일시정지하는 순간 일하는 에이전트는 **3명**이었다(두 번 모두). 소개 영상이 그 전에 끝난다. 그래서 대사를 "여러 에이전트가"로 바꿨다.
- 장면 7과 8은 붙어 온다. 다시 실행을 누르고 1초 안에 이미지 승인 결재가 뜬다. 상세 창을 닫고 바로 장면 8로 넘어간다.
- 장면 6에서는 배경 고르기가 장면 5 동안 이미 기다리고 있다. 페르소나 승인은 재개 7초 뒤에 뜬다.
- 일시정지와 구성 보기 중에는 승인 표시(선과 문구)가 멈춰 남는다. 일시정지한 채로 설명해도 된다.

## 시연 전 준비 (5분)

- 맥북 1512×982 해상도, Chrome 전체 화면(⌃⌘F). 1280 화면에서는 일부 관문 이름이 기호만 남는다.
- 인터넷 연결 확인. 글꼴(Pretendard)을 온라인에서 불러오므로, 연결이 없으면 시스템 글꼴로 바뀌고 이름표 배치가 달라질 수 있다.
- `d-ops.html#job/seoha-new/floor` 열기 → 시연 도구 → **처음부터** → 속도 **2×** → 자동 처리 **끔** → 상한 $30 → 시연 도구 닫기.
- **크게 보기(F)** 켜 두기. 다음에 열어도 켜진 상태로 열린다.
- 화면이 "시작 전", 오른쪽 위 목록에 "시작하면 일하는 에이전트가 여기에 나와요"가 보이면 준비 끝.
- 기록 패널은 **닫힌** 상태로 시작한다(머리 줄 "기록" 버튼이 눌리지 않은 상태).
- 마우스 포인터는 화면 가운데 아래 빈 바닥에 둔다(라인 이름 위에 두면 그 라인만 남고 흐려진다).

## 조작 요약

| 하고 싶은 것 | 조작 |
|---|---|
| 구성 안내 | H 또는 '구성 보기' → → 다음 · ← 이전 · Esc 닫기 (여는 동안 시간 멈춤) |
| 설명하려고 멈추기 | 오른쪽 위 '일시정지' / '다시 시작' |
| 한 라인 짚기 | 왼쪽 라인 이름에 마우스 올리기 |
| 작업 하나 짚기 | '지금 일하는 에이전트' 목록 줄에 마우스 올리기 → 바닥 칩이 함께 밝아짐 |
| 작업 상세 | 목록 줄 클릭 (바닥 작업대는 한 번 = 따라가기, 두 번 = 상세) |
| 결재 | 모래색 표시의 '고르기 →'(작업실로 이동) 또는 '승인' |
| 지나간 일·결재함 | 머리 줄 오른쪽 **기록** 버튼 또는 L. 열면 오른쪽에 "지나간 일 · 결재함 · 문제"가 펼쳐지고 공장이 그만큼 줄어든다. 닫혀 있을 때 버튼에 결재·문제 숫자와 새 사건 점이 뜬다. 지나간 일 줄을 누르면 공장에서 그 자리를 짚는다 |
| 빨리 감기 | 시연 도구 → 4× 또는 8× |

## 2배속 기준 실제 흐름 (사람 결재 대기 시간 제외)

시작 → 얼굴 고르기 4초 → 기획안 고르기 약 5초 뒤 → 배경 고르기·페르소나 승인 약 10초 뒤 → 클러스터 증강 '사람 필요' 약 16초 뒤 → 이미지 승인 약 4초 뒤 → 움직임 고르기 바로 → 표본 검수 약 12초 뒤 → 모든 작업 완료 약 25초 뒤.
위 숫자는 이전 측정값이다. 실제 리허설 기준 시각은 맨 위 표를 따른다. 결재가 대기 중인 동안 그 뒤 작업은 멈추지만, 다른 라인은 계속 움직인다. 말이 길어질 장면에서는 일시정지한다.
작업실에 가 있는 동안에도 시간은 흐른다(돌아올 때 최대 90초 분량 반영).

## 장면 1 · 오프닝 (0:00–0:30, 측정 0:25)

**화면** 시작 전 공장 현장, 크게 보기.

> "캐릭터 하나를 만들려면 기획, 얼굴, 배경, 영상, 성격, 학습 데이터, 모델까지 일곱 가지 일이 필요합니다. 이걸 AI 에이전트 스무 개가 나눠서 동시에 하고, 사람은 중요한 순간에만 결정합니다. 그 과정을 공장처럼 보여 주는 화면입니다."

## 장면 2 · 구성 보기 (0:30–1:30, 측정 0:45)

**조작** H. 단계마다 → (한 단계 10~15초).

1. 라인 = 팀 · 비주얼 라인 띠가 밝아진다
   > "가로줄 하나가 팀 하나입니다. 일은 왼쪽에서 오른쪽으로 흐릅니다."
2. 작업대 = 작업 하나
   > "상자 모양 하나가 작업 하나입니다. 에이전트가 여기서 일합니다."
3. 차단기 = 사람 결재
   > "차단기 표시가 있는 곳에서는 사람이 고르거나 승인해야 다음으로 넘어갑니다. 일곱 곳입니다."
4. 상자 = 산출물 (아직 상자가 없으므로 안내 문구 그대로)
   > "일이 끝나면 결과물 상자가 나와서 다음 작업으로 실려 갑니다."
5. 포장대 = 캐릭터
   > "모든 라인의 결과물이 여기 모이면 캐릭터 한 명이 완성됩니다."

**조작** 마지막 '끝내기' 또는 Esc.

## 장면 3 · 시작과 첫 결재 (1:30–2:40, 측정 0:49)

**조작** 배너의 **기획안 주입하고 시작** 클릭.
> "기획 브리프를 넣고 시작합니다. 오른쪽 위 목록이 지금 일하는 에이전트입니다."

약 4초 뒤 비주얼 라인에 모래색 **얼굴 고르기** 표시가 뜬다.
> "후보 얼굴 세 개가 나왔습니다. 여기서 사람이 고릅니다. 모래색은 사람을 기다린다는 뜻입니다."

**조작** **고르기 →** → 작업실에서 세 얼굴을 15초쯤 보여 준 뒤 하나 클릭 → **이 얼굴로 확정** → 1.3초 뒤 자동으로 공장 복귀.
> "고르면 바로 공장으로 돌아옵니다."

복귀 1초 뒤 **얼굴 고르기 → 비주얼 시작** 선과 문구가 뜬다(약 3초).
곧 **기준 사진**이 장밋빛 '재시도 중'이 될 수 있다.
> "고른 얼굴로 기준 사진을 만들고, 같은 사람인지 자동 검사합니다. 기준을 못 넘으면 사람을 부르지 않고 알아서 다시 만듭니다."

## 장면 4 · 결재 한 번에 세 팀 (2:40–3:30, 측정 0:29) ★핵심

기획 라인에 **기획안 고르기**가 뜬다.
> "기획안 세 개가 왔습니다. 같은 상황에서 서로 다르게 행동하는 세 사람입니다."

**조작** **고르기 →** → 작업실 위쪽 "같은 상황" 문장을 읽고, 세 사람의 "이럴 때 먼저 하는 행동"을 한 줄씩 읽어 준다(20초) → 1번 윤서하 클릭 → **이 사람으로 확정**.

복귀 직후 기획안 고르기에서 비주얼·마케팅·페르소나 세 라인으로 선이 그려지고 라인 이름이 밝아진다.
**조작** 복귀 1초 뒤 선이 그려지기 시작하면 바로 **일시정지**. 선과 문구가 그대로 남는다.
> "**지금 보세요.** 결재 한 번에 비주얼, 마케팅, 페르소나 세 팀이 동시에 출발합니다."

**조작** 일시정지한 채 **L**(기록 열기) → "지나간 일" 맨 위에 "기획안 고르기 확정 → 비주얼 · 마케팅 · 페르소나 시작", 그 아래 "기준 사진 자동으로 다시 만들어 통과"가 보인다 → 장면 5로 넘어가기 전에 **L**로 닫는다.
> "지나간 일은 여기 쌓입니다. 사람이 뭘 결정했고, 에이전트가 혼자 뭘 고쳤는지 기록이 남습니다."

## 장면 5 · 동시 작업 읽기 (3:30–4:30, 측정 0:49)

일시정지한 상태 그대로 이어 간다(목록은 보통 3줄).

> "지금 여러 에이전트가 동시에 일합니다. 목록 위 숫자가 지금 일하는 수입니다."

**조작** 목록 첫 줄(비주얼 · 배경 9장)에 마우스 → 바닥 칩이 밝아진다.
> "목록 한 줄이 바닥 작업대 하나입니다. 배경 탐색 에이전트가 배경 아홉 장 중 몇 장째를 만들고 있습니다."

**조작** 목록 둘째·셋째 줄로 내려가며 짚기.
**조작** 왼쪽 **페르소나** 라인 이름에 마우스.
> "라인 이름 아래에는 지금 무엇을 기다리는지가 나옵니다. 데이터셋은 페르소나 승인을 기다리고, 학습은 표본 검수를 기다립니다."

**조작** 마우스를 빈 곳으로 → 머리 줄 **재개**.

## 장면 6 · 승인 두 건 (4:30–5:00, 측정 0:24)

배경 고르기(비주얼)는 장면 5 동안 이미 기다리고 있고, 페르소나 승인은 재개 약 7초 뒤 뜬다.

**조작** 페르소나 승인 표시의 **승인** → **페르소나 승인 → 데이터셋 시작** 표시.
> "승인형 결재는 공장에서 바로 누릅니다. 이제 데이터셋 팀이 대화 데이터를 만들기 시작합니다."

**조작** 배경 고르기 **고르기 →** → 작업실에서 배경 클릭 → **이 배경으로 확정**.
시간이 빠듯하면 대본에서 이 결재를 빼고, 시연 도구의 자동 처리를 잠깐 켰다 끈다.

## 장면 7 · 사람이 필요한 순간 (5:00–5:30, 측정 0:16)

배경 고르기에서 돌아오고 약 3초 뒤 뜬다.

데이터셋 라인 **클러스터 증강**이 장밋빛 '사람 필요'가 된다. 목록에 장밋빛 줄이 생기고, 머리 줄 '문제'가 1이 된다.
> "에이전트가 세 번 시도해도 중복률 기준을 넘지 못했습니다. 이럴 때만 사람을 부릅니다."

**조작** 목록의 장밋빛 줄 클릭 → 상세 창 "시도 기록"에서 실패 3회를 짚은 뒤 **다시 실행** → 상세 창 닫기(× 또는 Esc). 1초 안에 장면 8 결재가 뜬다. 시간 여유가 있으면 **L**로 기록을 열어 "클러스터 증강 사람 필요" 위에 "다시 실행 · 사람 확인 후"가 쌓인 것을 보여 주고 닫는다(+10초).

## 장면 8 · 이미지 승인 (5:30–6:40, 측정 0:14 · 수정 요청 제외)

비주얼 라인에 **이미지 승인**이 뜬다. 7~8분을 채우려면 수정 요청을 기본으로 넣는다.

- **짧게 할 때**: **승인** → **이미지 승인 → 영상 · 마케팅 시작** 표시. 같은 순간 영상 라인에 움직임 고르기 결재가 열린다.
  > "완성 이미지를 승인하면 영상과 썸네일이 출발하고, 영상 팀은 바로 움직임을 고르라고 사람을 부릅니다."
- **기본(+1분)**: **검토** → 2장에 수정 요청을 고르고 메모 한 줄 입력(필수, 미리 정해 둔 문장 사용) → 2장만 다시 만들어지고 다시 올라오면 상세 창에서 수정 전후를 비교 → 승인.
  > "마음에 안 드는 장만 고쳐 달라고 하면, 그 장만 다시 만들고 전후를 나란히 보여 줍니다."

## 장면 9 · 마무리 (6:40–7:30, 측정 0:30)

**조작** 시연 도구 → **8×** → **자동 처리 켬** → 시연 도구 닫기.
> "남은 결재는 빠르게 넘기겠습니다."

움직임 고르기와 표본 검수가 자동으로 승인되고, 승인 순간 표시가 지나간다. 약 9초 뒤 모든 작업이 끝나고, 포장대 위에 **G9 출시 승인**이 뜬다.

**조작** 시연 도구 → 속도를 **2×**로 되돌리고 자동 처리 **끔**(다음 시연 대비) → **승인** → 캐릭터 카드가 '출시됨'으로 바뀐다 → 카드를 클릭해 캐릭터 페이지로 이동 → 자산 목록을 20초쯤 훑는다.
> "모든 라인의 결과물이 하나로 묶여 캐릭터 윤서하가 출시됐습니다. 사람은 일곱 번 결정했고, 나머지는 에이전트 스무 개가 나눠서 했습니다."

## 막혔을 때

| 상황 | 대처 |
|---|---|
| 결재가 예상보다 빨리 와서 말이 밀림 | 일시정지 후 설명 |
| 장면을 놓침 | 그대로 진행. 승인 순간 표시는 다음 결재에서 다시 보여 준다 |
| 작업실에서 오래 머묾 | 그 사이 시간이 흘러 결재가 여러 개 쌓일 수 있다. 하나씩 처리 |
| 화면이 꼬임 | 시연 도구 → 처음부터 → 장면 3부터 다시(약 30초 손실) |
| 라인 전체가 흐려짐 | 마우스가 라인 이름 위에 있음. 빈 바닥으로 옮기기 |

## 리허설 체크

- 장면 4에서 선이 그려지기 시작할 때 일시정지를 누를 수 있는지(작업실 복귀 1초 뒤 시작, 2.8초 동안 표시).
- 전체를 한 번 소리 내어 돌려 7~8분 안에 들어오는지. 넘치면 장면 6의 배경 고르기, 장면 8의 수정 요청부터 뺀다.
